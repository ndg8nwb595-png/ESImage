# Triage 标签

各技能使用五个规范的 triage 角色。本文件把这些角色映射到本仓库 issue 追踪器中实际使用的标签字符串。

| 技能中的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整定义，可由 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

当技能提到某个角色（例如“应用 AFK-ready triage 标签”）时，使用上表对应的标签字符串。

若实际使用的词表不同，修改“本仓库的标签”一列即可。
