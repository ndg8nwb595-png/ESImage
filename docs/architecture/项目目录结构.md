# 项目目录结构

本仓库为「ESImage 电商主图/详情图 AIGC 生成系统」的单仓多模块布局，前后端按业务域拆分，便于多个模块并行开发与独立维护。

## 1. 顶层结构

```text
ESImage/
├── backend/            # FastAPI 后端
├── frontend/           # React 18 + TypeScript 前端
├── docs/               # PRD、Agent 约定、ADR、接口与部署文档
├── infra/              # Nginx、Docker 等部署资源
├── scripts/            # 仓库级脚本（初始化、检查等）
├── docker-compose.yml  # 本地 PostgreSQL 等依赖
└── AGENTS.md
```

## 2. 后端结构

```text
backend/
├── app/
│   ├── main.py                 # 应用入口：挂载路由、异常处理、中间件
│   ├── core/                   # 跨模块基础设施
│   │   ├── config.py           # 环境变量配置
│   │   ├── database.py         # 引擎、会话、Base
│   │   ├── security.py         # bcrypt、JWT
│   │   ├── deps.py             # 鉴权依赖
│   │   ├── response.py         # 统一响应与业务异常
│   │   └── audit.py            # 审计日志写入
│   ├── models/                 # 共享 ORM 模型（全库唯一 metadata）
│   ├── schemas/                # 跨模块通用 Schema（分页等）
│   ├── modules/                # 业务模块，按 PRD 域拆分
│   │   ├── auth/               # 1 号：登录、登录态、退出
│   │   ├── workspace/          # 2 号：创作工作台
│   │   ├── chat/               # 3 号：Agent 会话交互
│   │   ├── generation/         # 4 号：生图任务与结果
│   │   ├── history/            # 5 号：历史作品
│   │   ├── profile/            # 9 号：个人中心
│   │   └── admin/              # 管理后台（6/7/8 号）
│   │       ├── dashboard/      # 概览
│   │       ├── accounts/       # 账号与权限
│   │       ├── content/        # 内容追溯、用户与生图记录
│   │       ├── assets/         # 素材与模板
│   │       ├── prompts/        # Agent 配置、聊天记录、模型配置
│   │       └── audit/          # 操作日志
│   └── seeds/                  # 全库种子编排（具体数据由各模块提供）
├── scripts/                    # 建表、种子等运维脚本
├── tests/                      # pytest
├── requirements.txt
└── pytest.ini
```

约定：

- 每个业务模块自带 `router.py`、`schemas.py`，需要独立业务逻辑时增加 `service.py`。
- ORM 模型统一放在 `app/models/`，避免跨模块循环依赖；模块只引用，不重复定义。
- 模块之间通过 `core/` 与 `models/` 通信，禁止直接 import 其他模块的 router。
- 新增模块时，在 `app/modules/` 下建同名目录，并在 `app/main.py` 注册路由。

## 3. 前端结构

```text
frontend/
├── src/
│   ├── app/
│   │   ├── main.tsx            # 应用入口
│   │   ├── App.tsx             # 根组件
│   │   └── router/             # 路由表与守卫
│   ├── modules/                # 业务模块，与后端域对应
│   │   ├── auth/               # 登录
│   │   ├── workspace/          # 创作工作台
│   │   ├── chat/               # Agent 会话
│   │   ├── generation/         # 生图结果
│   │   ├── history/            # 历史作品
│   │   ├── profile/            # 个人中心
│   │   ├── admin/              # 管理后台
│   │   └── errors/             # 403 / 404
│   ├── shared/
│   │   ├── api/                # fetch 封装、鉴权注入
│   │   ├── components/         # 通用组件
│   │   ├── layouts/            # 页面骨架、顶部导航
│   │   ├── store/              # 跨模块状态
│   │   ├── types/              # 共享类型
│   │   └── utils/              # 工具函数
│   ├── styles/                 # 全局样式与设计变量
│   ├── assets/                 # 静态资源
│   └── test/                   # vitest 初始化
├── public/
├── tests/                      # 预留端到端测试
├── index.html
├── package.json
├── tsconfig.json
└── vite.config.ts
```

约定：

- 页面、局部组件、模块 API 与 store 放在对应 `modules/<域>/` 内。
- 只有被两个以上模块使用的代码才上移到 `shared/`。
- 路由集中在 `app/router/`，业务模块不自行创建 BrowserRouter。

## 4. 模块与 PRD 对照

| 目录 | 对应文档 |
| --- | --- |
| `modules/auth` | 1-登录界面 |
| `modules/workspace` | 2-用户端创作工作台 |
| `modules/chat` | 3-Agent会话交互 |
| `modules/generation` | 4-生图任务与结果 |
| `modules/history` | 5-历史作品 |
| `modules/profile` | 9-后端服务与接口 §5.7 |
| `modules/admin/*` | 6/7/8-管理后台 |
| `core`、`models`、`seeds` | 9-后端服务与接口、10-数据模型与存储 |
| `infra` | 11-部署与运维 |

> 当前只有 `auth` 模块有实现；其余目录为占位，供后续模块并行开发。
