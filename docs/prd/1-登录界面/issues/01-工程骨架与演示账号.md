# 01: 工程骨架、最小数据表与演示账号

**What to build:** 建立一个可本地启动的前后端最小工程：前端能打开登录路由，后端能连接 PostgreSQL 并提供登录接口所需的运行环境；数据库只建登录链路需要的 6 张表；预置普通用户、管理员、双角色三个演示账号，密码以 bcrypt（cost=12）存储。完成后，后续切片可以直接在此基础上实现登录。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 前端使用 React 18 + TypeScript + Ant Design 5 + React Router v6 + zustand，`/login` 路由可打开。
- [ ] 后端使用 FastAPI，可启动并连接 PostgreSQL 16；数据库连接、JWT 密钥等配置通过环境变量注入，不写入代码仓库。
- [ ] 数据库包含 `users`、`roles`、`permissions`、`user_roles`、`role_permissions`、`audit_logs` 六张表，关键字段与 10 号数据模型文档一致。
- [ ] `users.username` 全局唯一（含已删除账号）；`users` 具备 `status`、`token_version`、`password_hash` 字段；`audit_logs` 具备 `username_snapshot`、`action`、`result`、`ip`、`user_agent`、`detail` 字段。
- [ ] 种子脚本幂等：重复执行不覆盖已有数据；三个演示账号的角色与权限正确。
- [ ] 演示账号为 `demo_user`（`user`）、`demo_admin`（`admin`）、`demo_dual`（`user` + `admin`），密码统一为 `Demo1234`；数据库只保存 bcrypt cost=12 哈希，不保存明文。
- [ ] 后端 pytest、前端 vitest 至少各有一个可执行的冒烟测试。
- [ ] 启动说明写明本地启动顺序、演示账号与最小 demo 的已知取舍（不接 Redis、不接 Alembic）。
