# 02: 登录接口与登录页闭环

**What to build:** 用户在登录页输入用户名、密码，勾选或不勾选「记住我」，前端完成校验后调用登录接口；后端校验账号密码并签发 JWT，前端保存 token 后跳转到角色默认落地页的占位页。登录成功与失败都写入审计日志。

**Blocked by:** 01（工程骨架、最小数据表与演示账号）

**Status:** ready-for-agent

- [ ] 用户名为空、格式不符，密码为空、长度不符时，在对应输入框下方显示 PRD 指定提示，且不发送登录请求。
- [ ] 用户名提交前去除首尾空格，区分大小写，规则为 4~20 位字母、数字或下划线；密码不去除空格，规则为 8~32 位。
- [ ] 登录成功返回 `token`、`expires_at`、`user`（含 `roles` 与 `permissions`）；前端把 token 存入 `localStorage` 的 `esimage_token` 键。
- [ ] 未勾选「记住我」时 token 有效期为 24 小时；勾选后为 7 天；有效期写入 JWT `exp`。
- [ ] 用户名不存在、密码错误、账号禁用、账号删除，前端统一显示「用户名或密码错误」，不泄露账号是否存在。
- [ ] 提交过程中登录按钮显示 loading 并禁用，防止重复提交。
- [ ] 登录成功与失败都写入 `audit_logs`；失败日志包含用户名快照、时间、IP、User-Agent、结果，不包含密码。
- [ ] 后端对用户名、密码格式与账号状态做二次校验，不依赖前端校验。
- [ ] 登录成功后跳转到角色默认落地页；此切片允许落地页为占位页。
