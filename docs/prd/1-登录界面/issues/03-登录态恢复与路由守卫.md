# 03: 登录态恢复、请求注入与路由守卫

**What to build:** 应用启动时读取本地 token 并调用 `/auth/me` 恢复当前用户；所有后端请求自动携带 `Authorization` 头；未登录访问受保护页面时跳转登录页并带回跳地址；收到 401 时清除 token 回登录；回跳地址只允许站内路径。

**Blocked by:** 02（登录接口与登录页闭环）

**Status:** ready-for-agent

- [ ] 有 token 时启动调用 `GET /api/v1/auth/me`，成功后写入 zustand 全局用户状态；刷新页面仍保持登录。
- [ ] 无 token 访问 `/workspace`、`/history`、`/profile`、`/admin/*` 时跳转 `/login?redirect=原路径`。
- [ ] 所有请求统一注入 `Authorization: Bearer <token>`。
- [ ] 收到 401 时清除 token 与全局用户状态，跳转 `/login?redirect=当前路径`。
- [ ] 收到 5xx 或网络异常时只展示统一提示，不自动登出。
- [ ] `redirect` 只接受以 `/` 开头且不以 `//` 开头的站内路径；站外地址忽略并按角色进入默认页。
- [ ] 已登录访问 `/login` 时按角色跳转默认页。
- [ ] `/workspace`、`/history`、`/profile`、`/admin/*`、`/403` 均有可访问的占位页，用于验证守卫与无权限跳转。
- [ ] 无权限访问管理端路由时进入 `/403`，不跳登录页。
