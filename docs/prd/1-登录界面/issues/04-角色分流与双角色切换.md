# 04: 角色分流与双角色切换

**What to build:** 登录成功或已登录访问 `/login` 时，按角色进入正确的默认页；双角色账号默认进入创作台，并在顶部提供「创作台 / 管理后台」切换；仅管理员或仅超管不显示创作台入口。

**Blocked by:** 03（登录态恢复、请求注入与路由守卫）

**Status:** ready-for-agent

- [ ] 仅普通用户登录后进入 `/workspace`。
- [ ] 仅管理员登录后进入 `/admin/dashboard`。
- [ ] 普通用户 + 管理员双角色登录后进入 `/workspace`。
- [ ] 双角色账号顶部显示「创作台 / 管理后台」切换，当前所在端高亮。
- [ ] 切换不重新登录、不重新签发 token，直接路由跳转。
- [ ] 仅管理员账号不显示「创作台」入口。
- [ ] 用 `demo_user`、`demo_admin`、`demo_dual` 三个账号分别验证落地页与切换结果。
- [ ] 无管理端权限的账号访问 `/admin/*` 时进入 `/403`。
