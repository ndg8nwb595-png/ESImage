# 05: 账号状态即时失效

**What to build:** 账号被禁用或软删除后，已签发的 token 立即不可用；`token_version` 递增后旧 token 也不可用；前端收到失败响应后清除登录态并回到登录页。

**Blocked by:** 03（登录态恢复、请求注入与路由守卫）

**Status:** ready-for-agent

- [ ] 每次携带 token 的请求都校验 JWT 签名、`exp`、`token_version` 与数据库中的账号状态。
- [ ] 最小 demo 直接查 PostgreSQL，不接 Redis；权限与状态变更即时生效。
- [ ] 账号 `status` 变为 `disabled` 或 `deleted` 后，旧 token 请求被拒绝，前端清除 token 并回到 `/login`。
- [ ] `users.token_version` 递增后，旧 token 请求被拒绝。
- [ ] 登录接口对禁用、删除账号仍返回统一的「用户名或密码错误」。
- [ ] 拒绝响应不包含账号是否存在、当前状态等敏感信息。
- [ ] 通过 SQL 修改账号状态即可完成演示，不依赖管理后台页面。
