# 06: 退出登录与审计

**What to build:** 用户点击「退出登录」后，前端调用退出接口记录审计，随后清除本地 token 与全局用户状态并回到登录页；退出后再次访问受保护页面必须重新登录。

**Blocked by:** 03（登录态恢复、请求注入与路由守卫）

**Status:** ready-for-agent

- [ ] 退出时调用 `POST /api/v1/auth/logout`，请求携带 `Authorization: Bearer`。
- [ ] 后端写入退出审计日志，包含用户名、时间、IP、User-Agent、结果 `success`。
- [ ] 服务端不维护 token 黑名单；退出以客户端清除 token 为准。
- [ ] 无论退出接口成功或失败，前端都清除 `localStorage` 中的 `esimage_token` 与 zustand 用户状态。
- [ ] 退出后跳转 `/login`；浏览器后退访问 `/workspace` 等受保护页面被守卫拦截。
- [ ] 退出审计不包含密码或 token。
