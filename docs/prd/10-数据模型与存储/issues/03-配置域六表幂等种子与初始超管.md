# 03: 配置域六表、幂等种子与初始超管

**What to build:** 建立配置域六张表：`templates`、`material_assets`、`model_configs`、`system_prompts`、`prompt_versions`、`size_presets`；提供可重复执行的种子命令，种入 3 个角色、23 个权限点、角色权限矩阵、4 条尺寸预设、8 个 Agent 的初始提示词与版本 1、1 条启用的模型配置；提供首个超管初始化命令，用户名与密码必须显式传入，密码以 bcrypt 存储。完成后，重复执行种子不会新增或覆盖数据；没有显式密码时不会静默创建超管；`db verify` 能确认 18 张表全部就位。

**Blocked by:** 02 内容域六表与数据约束

**Status:** ready-for-agent

- [ ] `templates`、`material_assets` 字段与 10 号 §4.12、§4.13 一致；`status` 仅 `active`/`disabled`；建立状态/排序索引，`material_assets.tags` 建立 GIN 索引；本切片只建表，不种模板与素材。
- [ ] `model_configs` 字段与 10 号 §4.14 一致；温度 0~2、超时 30~300、并发 1~16、重试 0~3；`is_active=true` 只允许一行（部分唯一索引）。
- [ ] `system_prompts` 字段与 10 号 §4.15 一致；`agent_code` 唯一；`current_version` 默认 1。
- [ ] `prompt_versions` 字段与 10 号 §4.16 一致；`(prompt_id, version)` 唯一；建立 `(prompt_id, version DESC)` 索引；`prompt_id` 外键 `ON DELETE RESTRICT`。
- [ ] `size_presets` 字段与 10 号 §4.18 一致；宽高为正整数；`(platform_name, width, height)` 唯一；建立状态/排序索引。
- [ ] 种子写入 3 个角色：`user`（普通用户）、`admin`（管理员）、`super_admin`（超管），均为内置角色。
- [ ] 种子写入 23 个权限点，权限码、名称、类型与超管专属标记与 10 号 §11、6 号 §11.1 一致；`group_name` 按模块写入（用户端 / 账号与权限 / 内容追溯 / 素材与模板 / Agent 配置 / 统计分析 / 数据导出），不参与权限判定；其中超管专属为 `admin.roles.view`、`admin.roles.edit`、`admin.model.view`、`admin.model.edit`、`admin.audit.view`、`admin.export`。
- [ ] 种子写入角色权限矩阵：`user` 拥有 4 个 `user.*` 权限；`admin` 拥有 13 个非超管管理端权限（6 个菜单 + 7 个操作）；`super_admin` 写入全部 23 条（用于展示，运行时仍可按角色绕过）；超管专属权限不得授予 `user` 或 `admin`，`db verify` 对矩阵做同样校验。
- [ ] 种子写入 4 条尺寸预设：淘宝/天猫、京东、拼多多、抖音，均为 1000×1000，启用状态。
- [ ] 种子写入 8 条系统提示词，`agent_code` 为 `planner`、`product_understanding`、`copywriter`、`prompt_builder`、`image_generator`、`quality_reviewer`、`repairer`、`platform_rule`，`current_version=1`；同时写入 8 条版本 1 记录，内容与当前提示词一致。
- [ ] 种子写入 1 条启用模型配置：服务商 `volcengine_ark`，Base URL 为演示占位地址，`api_key_ciphertext` 为空，温度 0.7、超时 120、并发 4、重试 1、上下文上限 32000，文本与图像模型为占位名，视觉模型为空。
- [ ] 种子命令连续执行两次，第二次不新增角色、权限、角色权限、尺寸、提示词、版本或模型配置；已修改的提示词内容、模型配置、角色权限不被覆盖。
- [ ] 首个超管初始化命令要求显式设置 `INITIAL_SUPER_ADMIN_USERNAME` 与 `INITIAL_SUPER_ADMIN_PASSWORD`；缺失、空值或使用常见弱口令时命令失败并给出中文提示，不创建账号。
- [ ] 超管密码以 bcrypt 哈希存储，`status=active`、`token_version=0`，并授予 `super_admin` 角色；重复执行时不重置已有密码、不重复授予角色。
- [ ] 提供共享脱敏函数：对密码、`password_hash`、API Key、JWT、`Authorization` 等字段在写入审计日志或 Agent 输入输出前替换为占位文本；用例覆盖嵌套 JSON 与常见键名。
- [ ] `db verify` 扩展到 18 张表，并检查种子条数与超管初始化结果；任一项缺失时退出码非 0。
- [ ] 本切片不实现模板/素材/尺寸的增删改查接口，不实现角色权限编辑页面，不创建普通用户或管理员演示账号。
