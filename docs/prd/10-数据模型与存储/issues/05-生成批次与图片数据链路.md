# 05: 生成批次与图片数据链路

**What to build:** 在内容域表之上跑通生成数据链路：创建 `sample` 示例批次与 `full` 全套批次，保证 `full` 必须引用一个已存在的示例批次；写入批次参数快照、商品/风格/尺寸/模板快照与计划张数；写入示例图与正式图，保证示例批次只有主图、全套批次为 1 张主图 + 5 张详情图；拒绝非法批次状态、非法图片状态流转与不符合历史可见性规则的图片。本切片不实现生成管线与 HTTP，只交付可被 2/4 号 demo 调用的数据层能力与用例。

**Blocked by:** 03 配置域六表、幂等种子与初始超管

**Status:** ready-for-agent

- [ ] 创建示例批次时 `batch_type=sample`、`source_sample_batch_id` 为空、`params_snapshot` 非空、`product_name`/`width`/`height`/`total_count` 必填；示例批次允许的状态为 `queued`、`running`、`sample_ready`、`confirmed`、`failed`、`cancelled`。
- [ ] 创建全套批次时 `batch_type=full`、`source_sample_batch_id` 必填且指向一个 `batch_type=sample` 的批次；全套批次允许的状态为 `queued`、`running`、`completed`、`partially_failed`、`failed`、`cancelled`。
- [ ] `stage` 只能为 `NULL` 或 8 个 Agent、`text_composition`、`done`；`status=queued` 时 `stage` 为空；状态与阶段组合不符合 10 号 §4.9/§5 时被拒绝。
- [ ] 同一用户用相同 `client_request_id` 重复创建批次时返回已存在批次，不新增行；不同 `client_request_id` 创建新批次。
- [ ] `completed_count` 不超过 `total_count`；`started_at` 在进入 `running` 时写入，`finished_at` 在进入终态时写入；未进入终态时 `finished_at` 为空。
- [ ] 示例批次的图片 `image_type=sample`、`image_role=main`、`index_no` 从 0 或 1 起稳定递增；示例批次不得出现 `detail` 图片。
- [ ] 全套批次的图片 `image_type=final`，固定为 1 张 `main` + 5 张 `detail`；`index_no` 在组内稳定；复用示例图时，主图通过 `source_image_id` 指向示例图，原示例图保留。
- [ ] 图片状态只允许 `pending → generating → success/failed/cancelled` 与 `success/failed → superseded`；`success → generating`、`cancelled → success` 等非法流转被拒绝；`success` 不回退。
- [ ] 重试或重生成创建新的图片记录，`attempt_no` 递增；旧记录标记 `superseded`；新记录通过 `source_image_id` 指向被替代图片。
- [ ] `is_history_visible` 只有在「属于 `full` 批次、`image_type=final`、`status=success`、批次状态为 `completed` 或 `partially_failed`」时才允许为 true；示例图、失败图、取消半成品、被替代旧图必须为 false。
- [ ] 图片 `file_path`、`thumbnail_path` 在 `success` 前可为空；成功时必须写入规定路径；`archived_at` 默认空，归档后由 07 切片回写。
- [ ] `generated_images` 的 `batch_id`、`user_id`、`session_id` 必须一致地指向同一批次及其归属；跨用户或跨会话写入被拒绝。
- [ ] 用例覆盖示例批次、全套批次、`full` 缺少 `sample` 引用、非法状态、非法图片流转、1 主图 + 5 详情图、替代图与历史可见性；每步输出中文日志（操作、预期、实际、结论）。
- [ ] 本切片不实现示例图确认、批量生成、重试、取消、ZIP 下载等 HTTP 行为；这些属 4/5 号 demo。
