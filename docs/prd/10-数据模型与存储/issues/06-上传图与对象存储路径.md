# 06: 上传图与对象存储路径

**What to build:** 建立单桶对象存储适配层与上传图元数据链路：合法的 JPG/PNG/WEBP 商品图上传后，原件与缩略图落在规定的前缀路径，`uploaded_assets` 记录文件名、MIME、大小、宽高、排序与状态；超过 10MB、格式不符、扩展名与 MIME 不符、无法解码的文件被拒绝；缩略图最大宽 400px、WebP、质量 80；对象没有公开访问入口，读取必须经过后端鉴权。本切片不实现 HTTP 上传接口，只交付可被 2 号 demo 调用的存储适配器与数据层能力。

**Blocked by:** 03 配置域六表、幂等种子与初始超管

**Status:** ready-for-agent

- [ ] 存储适配层固定使用单桶 `esimage`，对象键为桶内相对路径，不带前导斜杠、不包含 `..` 或用户输入的文件名；默认后端为本地目录，目录结构等价于桶内前缀。
- [ ] 提供对象写入、读取、存在性检查、大小/元数据读取、复制、删除六类操作；复制用于归档，删除用于归档完成后的原件清理；对象不存在时返回可区分的“不存在”结果，不抛裸异常。
- [ ] 上传图原件路径为 `uploads/{user_id}/{session_id}/{uuid}.{ext}`；上传时尚未绑定会话的，使用 `uploads/{user_id}/unbound/{uuid}.{ext}`，首次绑定会话时只回填 `session_id`、不移动对象，`file_path` 保持创建时的值。
- [ ] 生成图原件路径为 `generated/{user_id}/{session_id}/{batch_id}/{uuid}.png`；生成图缩略图路径为 `thumbnails/{user_id}/{session_id}/{batch_id}/{uuid}_thumb.webp`；上传图缩略图路径为 `thumbnails/{user_id}/{session_id}/{uuid}_thumb.webp`，未绑定会话时使用 `thumbnails/{user_id}/unbound/{uuid}_thumb.webp`。
- [ ] 归档路径为 `archive/{原相对路径}`；`exports/`、`templates/`、`materials/`、`avatars/` 只保留前缀约定，本切片不写入。
- [ ] 对象名使用 UUID，扩展名来自校验后的真实格式；原始文件名只写入数据库，不进入对象路径。
- [ ] 上传校验：允许 JPG、PNG、WEBP；MIME 与扩展名必须一致；单文件不超过 10MB；文件可被解码；宽高可读取；任一不满足时拒绝并给出可读原因，不落库、不落对象。
- [ ] 缩略图生成：最大宽度 400px，高度等比缩放；输出 WebP、质量 80；原图宽度不超过 400px 时不放大，仍输出 WebP；生成失败时不写入 `thumbnail_path`，原件仍保留。
- [ ] `uploaded_assets` 写入 `original_name`、`mime_type`、`size_bytes`、`width`、`height`、`sort_order`、`status=active`；`session_id` 可空；`sort_order` 按上传顺序稳定递增，首张为主参考图；`status=deleted` 为软删除，不物理删除记录。
- [ ] 存储桶不公开：不生成公开 URL、不依赖静态目录直出；读取通过适配层加后端鉴权完成；未鉴权或非归属用户的读取被拒绝。
- [ ] 同一用户的未绑定上传图数量由调用方控制，本切片只保证元数据与路径正确，不实现「最多 5 张」的 HTTP 校验（属 2 号 demo）。
- [ ] 用例覆盖：合法 JPG/PNG/WEBP、GIF、超 10MB、损坏文件、扩展名与 MIME 不符、未绑定与已绑定会话的路径、缩略图尺寸与格式、鉴权读取、软删除；每步输出中文日志（操作、预期、实际、结论）。
- [ ] 本切片不实现上传 HTTP 接口、上传数量限制、预签名 URL、孤儿上传清理；这些分别属 2/9/10 号完整实现。
