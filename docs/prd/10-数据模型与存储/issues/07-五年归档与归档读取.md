# 07: 五年归档与归档读取

**What to build:** 提供可手动触发、可注入时钟的归档任务：扫描 `generated_images` 与 `uploaded_assets` 中超过保留期且尚未归档的记录，把原件从 `generated/` 或 `uploads/` 复制到 `archive/`，校验复制结果后删除原件、回写 `archived_at`；缩略图保持在 `thumbnails/` 热存，数据库记录不删除。单条失败不影响其他记录，下次执行可重试。读取已归档图片时从 `archive/` 取原件；归档对象缺失时返回 `404 30014`。本切片不实现每日调度，只交付任务本体与读取降级。

**Blocked by:** 05 生成批次与图片数据链路；06 上传图与对象存储路径

**Status:** ready-for-agent

- [ ] 归档任务支持 `esimage-data archive run --now <ISO8601>` 手动触发；`--now` 缺省时取当前时间；所有时间按 Asia/Shanghai 解释。
- [ ] 保留期由 `ARCHIVE_RETENTION_DAYS` 控制，默认 1825 天；截止时间 = `now - 保留期`；demo 可调小以验证超期记录。
- [ ] 扫描 `generated_images` 与 `uploaded_assets` 中 `created_at < 截止时间`、`archived_at IS NULL`、`file_path` 非空的记录；已归档记录不重复处理。
- [ ] 对每条记录：把原件复制到 `archive/{原 file_path}`，校验归档对象存在且大小与原件一致；校验成功后删除原件；删除成功后回写 `archived_at`。
- [ ] 缩略图不复制、不删除、不改 `thumbnail_path`；归档后缩略图仍在 `thumbnails/` 可读。
- [ ] 数据库记录不删除；`file_path` 保留原值，归档后的读取通过 `archived_at` 判断改读 `archive/` 路径。
- [ ] 单条记录失败时记录失败原因、保持 `archived_at` 为空、不删除原件，并继续处理其他记录；单条失败不中断任务，任务结束时汇总失败数；存在失败时命令退出码非 0。
- [ ] 重复执行幂等：已归档记录跳过；若归档对象已存在但原件仍在，校验后删除原件并回写 `archived_at`；若归档对象已存在且原件已不存在，直接回写 `archived_at`；不产生重复对象或重复归档。
- [ ] 任务日志包含扫描数、成功数、失败数、跳过数与耗时；失败记录指出表名、记录 ID、对象键与原因；日志为中文。
- [ ] 读取接口/服务按 `archived_at` 选择路径：为空读原件路径；非空读 `archive/{原 file_path}`；对象不存在或存储不可用时返回 `404 30014`，提示「文件归档中，请稍后重试」；不得回退读取已删除的原件路径。
- [ ] 生成图与上传图两类记录都覆盖：至少 1 张超期生成图、1 张超期上传图被归档；至少 1 条未超期记录不被处理；至少 1 条归档读取成功、1 条归档缺失返回 `30014`。
- [ ] 用例覆盖复制失败、删除失败、重试成功、重复执行、缩略图保留、数据库记录保留；每步输出中文日志（操作、预期、实际、结论）。
- [ ] 本切片不实现每日 03:00 调度、孤儿上传清理、导出文件清理与数据库备份；调度属 11 号，孤儿清理与导出清理不在本 demo 内。
