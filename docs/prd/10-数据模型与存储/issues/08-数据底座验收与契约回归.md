# 08: 数据底座验收与契约回归

**What to build:** 提供一条命令完成本地数据底座初始化（迁移 + 种子 + 首个超管），并提供一套可重复执行的契约回归：逐项验证 18 张表、迁移回滚、幂等种子、首个超管、会话/消息/Agent 数据链路、批次/图片数据链路、上传与存储路径、归档与 `30014` 读取降级。回归必须输出中文日志，失败时明确指出「操作、预期、实际、结论」并以非 0 退出码结束，便于在单个新的上下文窗口内定位问题。

**Blocked by:** 01 迁移骨架与身份/审计表；02 内容域六表与数据约束；03 配置域六表、幂等种子与初始超管；04 会话、消息与 Agent 调用数据链路；05 生成批次与图片数据链路；06 上传图与对象存储路径；07 五年归档与归档读取

**Status:** ready-for-agent

- [ ] 提供 `esimage-data bootstrap`：在空库上执行迁移、种子与首个超管初始化；超管用户名/密码仍要求显式环境变量；任一步失败时停止并输出中文原因，不留下半初始化状态。
- [ ] 提供 `esimage-data verify --scope schema|seed|storage|archive|all`；`all` 覆盖本 demo 的全部验收项；每个 scope 可单独运行。
- [ ] schema 校验覆盖 18 张表的列、类型、空值、默认值、`CHECK`、唯一约束、部分唯一索引、普通索引与外键；报告 18/18，并列出每张表的检查结果。
- [ ] 迁移校验：`downgrade base` 后本 demo 表全部移除，`upgrade head` 后重新建立；两次迁移之间无残留对象；迁移脚本不删除业务数据。
- [ ] 种子校验：连续执行两次 `seed`，第二次不新增行；角色 3、权限 23、超管权限 23、尺寸 4、提示词 8、提示词版本 8、启用模型配置 1；修改过的提示词内容不被覆盖。
- [ ] 超管校验：缺用户名、缺密码、弱口令分别失败；显式密码成功且为 bcrypt；重复执行不重置密码；账号具备 `super_admin` 角色。
- [ ] 会话与消息校验：重复 `(session_id, client_message_id)` 只落一条；并发同一条首条消息只建一个会话；消息按 `(created_at, id)` 稳定排序；隐藏会话可读；Agent 调用状态、Token、耗时与脱敏正确。
- [ ] 批次与图片校验：`full` 缺 `sample` 引用被拒绝；示例批次只有 `main`；全套批次为 1 `main` + 5 `detail`；非法状态流转被拒绝；`superseded` 与历史可见性规则正确。
- [ ] 存储校验：上传图与生成图路径符合规则；UUID 对象名；10MB、MIME、扩展名、可解码校验；缩略图最大宽 400px、WebP、质量 80；未鉴权读取被拒绝。
- [ ] 归档校验：超期生成图与上传图迁入 `archive/`、原件删除、`archived_at` 回写、缩略图保留、数据库记录保留；重复执行幂等；读取归档成功；归档缺失返回 `404 30014`。
- [ ] 回归输出中文日志，逐项包含操作、预期、实际、结论；失败项汇总在末尾并返回非 0；成功时输出总通过数与被跳过的验收项。
- [ ] 回归可重复执行：每次运行前清理本 demo 的测试数据与测试对象，不污染已有业务数据；不依赖网络、豆包、Redis、Celery 或真实 MinIO。
- [ ] 回归报告末尾列出 10 号 §12 的覆盖情况：本 demo 覆盖 1、2、3、5、6、7、8、9、10、13、14；4 由 6 号 demo 验收，11 由 7 号 PRD 验收，12 由 11 号 PRD 验收。
- [ ] 本切片不新增业务能力，不修复前序切片的实现问题；发现失败时指出对应 Ticket 与具体断言。
