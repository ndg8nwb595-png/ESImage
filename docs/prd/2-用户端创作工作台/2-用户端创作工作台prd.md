## 1. 文档目的与范围

### 1.1 目的

定义普通用户完成一次创作的页面：布局、参数面板、商品图上传、模板入口、前端校验、生成入口与结果区状态。

### 1.2 本期范围

- 创作工作台整体布局与导航。
- 参数面板（商品名称必填；风格、尺寸、商品图、模板选填）。
- 商品图上传（可选，1~5 张）。
- 模板独立入口。
- 前端必填校验与请求拦截。
- 生成示例图/确认生成全套的入口。
- 结果区的展示与操作。
- 与聊天区、历史作品、个人中心的衔接。

### 1.3 不做

- 在线图片编辑（裁切、改字、局部重绘）。
- 批量提交多个商品。
- 用户自建模板、自选字体/颜色。
- 手机端完整适配。
- 生成参数中的高级项（负面提示词、随机种子、参考图权重）。

## 2. 页面布局

### 2.1 整体结构

桌面端三栏布局，最小宽度 1280px。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 顶部导航：创作台 | 历史作品 | 个人中心                [创作台/后台] 用户 ▾     │
├───────────────┬──────────────────────────────┬───────────────────────────────┤
│ 会话列表       │ 聊天框                         │ 参数面板                       │
│ [新建会话]     │ 消息流                         │  商品名称* [_________]         │
│ ┌───────────┐ │                                │  风格（选填）[________]        │
│ │ 会话 A    │ │                                │  尺寸（选填）[下拉 ▾]          │
│ │ 会话 B    │ │                                │  商品图   [上传区 0/5]         │
│ │ ...       │ │                                │  模板卡片区                    │
│ └───────────┘ │                                │                                │
│               │                                ├───────────────────────────────┤
│               │ 输入框（商品名称填写后可用）    │ 结果区                         │
│               │                                │  ┌──────────────────────────┐ │
│               │                                │  │ 示例图 / 结果网格 / 进度  │ │
│               │                                │  └──────────────────────────┘ │
└───────────────┴──────────────────────────────┴───────────────────────────────┘
```

### 2.2 尺寸与滚动

- 顶部导航固定高度 56px。
- 三栏宽度建议：会话列表 240px（固定，可折叠）、聊天框最小 360px（自适应）、参数面板 + 结果区最小 600px（占剩余宽度）。
- 三栏各自独立滚动；参数面板吸顶，结果区滚动。
- 页面整体不出现横向滚动条；窗口宽度不足 1280px 时优先压缩聊天框，再折叠会话列表。

## 4. 参数面板

### 4.1 字段定义

| 字段 | 控件 | 必填 | 规则 | 默认值 |
| --- | --- | --- | --- | --- |
| 商品名称 | 单行输入框 | 是 | 去除首尾空格；1~60 个字符；不允许纯空格 | 空 |
| 风格 | 单行输入框 | 否 | 自由文本，1~50 个字符；不填时由对话 Agent 推荐 | 空 |
| 尺寸 | 下拉 + 自定义宽高 | 否 | 不选时默认 1:1、1000×1000；宽高为正整数 | 1000×1000 |
| 商品图 | 上传组件 | 否 | 0~5 张；JPG/PNG/WEBP；单张 ≤10MB | 空 |
| 模板 | 模板卡片 | 否 | 点击应用；可取消 | 未选择 |

### 4.2 商品名称

- 用户手工填写，**不由 Agent 回填**。
- 商品类目由商品理解 Agent 根据名称、上传图和聊天内容推断。
- 输入长度实时提示，超出 60 字符时禁止继续输入或截断并提示。
- 商品名称用于页面展示、下载文件命名与后台检索。

### 4.3 风格

- 风格为**自由文本输入框**，不是下拉选择，也不再由后台维护风格配置。
- 用户可填写任意风格描述，如「简洁白底」「高级质感」「国潮」。
- 不填写时，对话中的规划 Agent 根据商品名称与需求列出 3~5 个合适的风格建议，用户可用自然语言选择，也可自行补充。
- 生成时以用户填写的文本为准；未填写且未在对话中明确时，由 Agent 结合商品画像选择。
- 风格文本快照写入生成批次，后续修改不影响历史记录。
- 输入长度 1~50 个字符；纯空格视为未填写。

### 4.4 尺寸

- 平台预设：

| 预设 | 宽 | 高 |
| --- | --- | --- |
| 淘宝/天猫 | 1000 | 1000 |
| 京东 | 1000 | 1000 |
| 拼多多 | 1000 | 1000 |
| 抖音 | 1000 | 1000 |
| 自定义 | 用户填写 | 用户填写 |

- 尺寸为选填；**不选择时，所有图片默认 1:1、1000×1000**。
- 自定义宽高必须为正整数；具体可用范围以后端按豆包模型能力校验为准，前端先做基础格式校验。
- 平台预设由后台维护，后台可增删改。

### 4.5 图片构成

- 每次生成固定为 **1 张主图 + 5 张详情图**，共 6 张。
- 示例图即主图；确认后生成 5 张详情图，主图不重复生成。
- 参数面板不再提供“产出类型”字段。

### 4.6 参数快照

- 点击「生成示例图」时，前端把当前参数作为快照提交。
- 参数同时保存在浏览器 localStorage（键名 `esimage_workspace_params_{session_id}`，按会话存储），刷新或切换会话后可恢复；新建会话参数为空；换设备或清缓存会丢失。
- 生成过程中即使前端参数被修改，不影响已提交任务。
- 快照用于后台追溯与问题复现。

## 5. 商品图上传

### 5.1 交互

- 支持点击选择文件与拖拽上传。
- 上传后展示缩略图网格，最多 5 张。
- 每张缩略图支持：预览、删除、替换、拖动排序。
- 第一张标记为「主参考图」，用于图生图时优先参考。
- 排序仅在前端维护：点击生成时按 `upload_ids` 提交顺序写回 `sort_order`，不提供单独的排序保存接口。
- 未上传商品图时，允许生成，走纯文生图。

### 5.2 校验

| 项目 | 规则 | 提示 |
| --- | --- | --- |
| 数量 | 0~5 张 | 最多上传 5 张商品图 |
| 格式 | JPG / JPEG / PNG / WEBP | 仅支持 JPG、PNG、WEBP 格式 |
| 大小 | 单张 ≤10MB | 单张图片不能超过 10MB |
| 可读性 | 后端校验图片可解码 | 图片文件损坏，请重新上传 |

- 前端校验不通过时，不发起上传请求。
- 后端必须二次校验；不通过返回明确错误码。
- 后端数量校验：该用户「未绑定会话且 `active`」的上传总数不超过 5 张，超过返回错误码 `30006`；绑定会话后释放名额。
- 上传成功后返回 `upload_id`，生成时提交 `upload_ids`。
- 上传中的文件显示进度；上传失败可单张重试。

### 5.3 上传与生成的关系

- 上传图作为图生图参考，不直接出现在结果区。
- 上传图长期保存在 MinIO，供后台追溯。
- 上传图 ID 保存在 localStorage；刷新后通过 `GET /api/v1/uploads/{upload_id}` 恢复缩略图。
- 删除上传图仅从当前创作中移除，不删除已生成记录中的引用。
- 孤儿上传清理：每日定时任务将「30 天未绑定会话且未被批次引用」的上传置为 `deleted` 并删除 MinIO 对象（详见 10 号文档 §7.5）。

## 6. 模板入口

### 6.1 位置

- 参数面板下方，独立卡片区，不与参数下拉混排。
- 标题「模板」，右侧提供「不使用模板」清除按钮。

### 6.2 展示

- 横向滚动卡片列表。
- 每张卡片包含：缩略图、模板名称、风格文案标签（可选）。
- 仅展示启用中的模板。
- 当前选中的模板显示高亮边框与勾选标记。

### 6.3 应用规则

1. 点击模板卡片后，把模板携带的默认风格文案填入风格输入框（用户可修改）；取消模板时保留当前风格文本，不回滚、不清空。模板不携带图片角色，也不携带尺寸。
2. 模板定义整套 6 张图（1 主图 + 5 详情图）的视觉体系，由规划 Agent 分配到每张图。
3. 用户仍可手动修改风格、尺寸、商品图等参数。
4. 生成时提交 `template_id`，后端记录模板快照。
5. 不选择模板时，由规划 Agent 自动设计版式。

## 7. 前端校验

### 7.1 必填校验

点击「生成示例图」或尝试发送聊天消息时，前端检查：

| 字段 | 校验 |
| --- | --- |
| 商品名称 | 非空、≤60 字符 |
| 尺寸（填写时） | 自定义宽高为正整数 |
| 风格（填写时） | 1~50 个字符 |

### 7.2 拦截规则

1. 商品名称为空或超过 60 字符时：
   - 弹出提示框「请先填写商品名称」。
   - 焦点移动到商品名称输入框。
   - **不发送任何网络请求**。
2. 商品名称未填写时，聊天输入框禁用，占位文案「请先填写商品名称后再开始对话」。
3. 商品名称填写后，聊天输入框与「生成示例图」按钮同时可用；风格、尺寸、商品图、模板均为选填。
4. 风格未填写时，聊天中由 Agent 推荐风格；尺寸未选择时按 1:1、1000×1000 生成。
5. 前端校验只是第一道防线；后端仍需校验商品名称与参数格式。

### 7.3 生成中限制

- 当前存在 `queued` / `running` 的生成批次时，「生成示例图」按钮禁用，显示「正在生成…」；`sample_ready` 不计入。
- 同一用户同时只允许 1 个 `queued` / `running` 批次；等待确认的示例不阻塞重新生成或确认。
- 用户可点击「取消任务」。

## 8. 生成入口与流程

### 8.1 生成示例图

1. 商品名称校验通过。
2. 点击「生成示例图」。
3. 前端提交参数快照、`upload_ids`、`session_id`（没有则后端创建会话）、`template_id`。
4. 后端创建 `sample` 批次，返回 `batch_id`。
5. 结果区进入「生成中」，按阶段展示进度。
6. 示例图生成完成后，展示示例图与三个操作：
   - 重新生成示例
   - 调整参数（回到参数面板，修改后需重新生成示例）
   - 确认并生成全套

### 8.2 示例确认循环

- 用户可反复「改参数 → 重新生成示例 → 查看 → 再改」，直到满意。
- 每次「重新生成示例」创建新的 `sample` 批次，旧示例批次保留可追溯，但结果区只展示最新示例。
- 只有最新一次 `sample_ready` 的示例可以确认。
- 旧示例处于 `sample_ready` 时不占并发名额，不会阻塞重新生成或确认。
- 确认前示例图不可下载（仅可预览）。

### 8.3 确认并生成全套

1. 用户点击「确认并生成全套」，二次确认「确认后将生成 5 张详情图，主图会计入最终结果」。
2. 后端创建 `full` 批次，引用当前 `sample` 批次。
3. 示例图（主图）作为全套第 1 张，不重复生成。
4. 系统生成 5 张详情图。
5. 结果区展示批量进度与张数。

### 8.4 取消任务

- 生成中或等待确认时可取消。
- 取消后批次状态为 `cancelled`。
- 已生成成功的图片保留在后台记录中，但不进入历史作品。
- 取消前需二次确认。

## 9. 结果区

### 9.1 状态与展示

| 状态 | 展示 |
| --- | --- |
| 空状态 | 插画 + 文案「填写参数后生成示例图」 |
| 示例生成中 | 分阶段进度：需求理解 → 文案生成 → 提示词构建 → 图像绘制 → 质量审核 |
| 示例待确认 | 示例图大图 + 三个操作按钮 |
| 全套生成中 | 进度条 + 已完成/总数（如 2/6） |
| 全部完成 | 结果网格，按序号排列 |
| 部分失败 | 成功图正常展示，失败张显示占位与「重试」 |
| 全部失败 | 错误提示 + 「重新生成」 |
| 已取消 | 提示「任务已取消」，保留已生成图片的缩略预览（不可下载） |

### 9.2 结果网格

- 1 张主图 + 5 张详情图，共 6 张，按生成顺序编号。
- 每张图展示：缩略图、序号、状态角标。
- 点击缩略图打开大图预览。
- 失败张显示失败原因摘要与「重试」按钮。

### 9.3 操作

| 操作 | 说明 |
| --- | --- |
| 预览 | 打开大图弹层，支持缩放查看、关闭 |
| 单张下载 | 下载 PNG |
| 整组下载 | 打包 ZIP，包含全部成功图片与 `manifest.csv` |
| 重生成该张 | 二次确认后新增一条生成记录，旧图保留但不在结果区展示 |
| 重试失败张 | 与重生成该张相同 |
| 取消任务 | 仅生成中/待确认时可用 |

### 9.4 文件命名

- 单张：`{商品名称}_{主图|详情图}_{序号}_{yyyyMMddHHmmss}.png`
- 整组：`{商品名称}_全套_{yyyyMMddHHmmss}.zip`
- 商品名称中的文件名非法字符替换为下划线。

### 9.5 下载权限

- 示例图在确认前不可下载。
- 正式图（含确认后的示例图）可下载。
- 失败图、取消任务的半成品不可下载。

## 10. 聊天区

- 会话列表位于页面最左侧独立栏；聊天框位于中间栏，详细规则见 `../3-Agent会话交互/3-Agent会话交互prd.md`。
- 商品名称未填写时输入框禁用；填写后可用。
- 聊天不直接触发生成；生成必须点击按钮。
- 聊天中形成的需求摘要会随示例生成请求一起提交。

## 11. 权限与数据边界

1. 仅拥有普通用户角色的账号可访问创作工作台。
2. 用户只能看到自己的会话、上传图、生成记录。
3. 用户不能删除历史作品；会话可软删除（仅本人隐藏）。
4. 用户不能修改已生成图片的参数快照。
5. 管理员通过后台查看用户内容，不进入用户的工作台。

| 上传超数量 | 最多上传 5 张商品图 | Toast |
| 上传格式错 | 仅支持 JPG、PNG、WEBP 格式 | Toast |

## 13. 验收标准

1. 页面为三栏布局，1280px 宽度下会话列表、聊天框、参数与结果三块可见且无横向滚动。
2. 参数面板包含商品名称（必填）、风格（选填文本）、尺寸（选填，默认 1:1）、商品图上传与模板入口。
3. 商品名称为空时点击生成或发送聊天，弹窗提示且不发送请求。
4. 商品名称填写后聊天输入框与生成按钮可用；其余字段选填。
5. 商品图支持 0~5 张、JPG/PNG/WEBP、单张 ≤10MB，支持删除、替换、排序。
6. 模板为独立卡片入口，点击可应用并高亮，可清除。
7. 点击生成示例图后展示分阶段进度。
8. 示例图支持重新生成、调整参数、确认生成全套的循环。
9. 确认后生成 1 张主图 + 5 张详情图，共 6 张，示例图即主图。
10. 结果区支持预览、单张下载、整组 ZIP、重生成、重试失败张、取消任务。
11. 生成的示例图在确认前不可下载。
12. 生成中同一用户不能发起第二个批次。
