# 01: 工作台骨架、最小数据表与演示配置

**What to build:** 普通用户登录后可以进入 `/workspace`，看到桌面端三栏创作工作台骨架：左侧会话列表、中间聊天框、右侧参数面板与结果区；顶部导航含创作台、历史作品、个人中心；结果区空状态显示「填写参数后生成示例图」。数据库具备后续切片需要的会话、消息、生成批次、生成图片、上传图五张表，演示用户具备工作台、生成、下载权限。管理员账号不能进入工作台。

**Blocked by:** 1 号 demo 的 01~03（工程骨架、登录闭环、登录态与路由守卫）。本切片不重复实现登录。

**Status:** ready-for-agent

- [ ] `/workspace` 路由登录后可访问；未登录访问跳转 `/login?redirect=/workspace`。
- [ ] 1280px 宽度下三栏同时可见：会话列表 240px（固定）、聊天框最小 360px（自适应）、参数面板 + 结果区最小 600px（占剩余宽度）；页面无横向滚动条。
- [ ] 顶部导航固定高度 56px，含「创作台」「历史作品」「个人中心」；当前页「创作台」高亮；后两者为可跳转的占位页。
- [ ] 三栏各自独立滚动；参数面板吸顶，结果区可滚动。
- [ ] 结果区空状态展示插画与文案「填写参数后生成示例图」；会话列表空状态可展示「暂无会话」。
- [ ] 数据库建立 `creative_sessions`、`chat_messages`、`generation_batches`、`generated_images`、`uploaded_assets` 五张表，字段、空值、默认值、枚举与索引与 10 号文档 §4.6~§4.11 一致。
- [ ] `generated_images.image_role` 支持 `main` / `detail`；`generation_batches.status` 与 `stage` 枚举与 10 号 §5 一致。
- [ ] 种子脚本幂等：为 `demo_user` 补种 `user.generate`，并确保其具备 `user.workspace`、`user.history`；不覆盖已有修改。
- [ ] 拥有普通用户角色且具备 `user.workspace` 的账号可访问工作台；仅有管理员角色或缺少权限的账号访问 `/workspace` 被路由守卫拦截，接口返回 403 `20005`。
- [ ] 后端 pytest、前端 vitest 至少各有一个工作台骨架冒烟测试；启动说明写明本地启动顺序、演示账号与本最小 demo 的取舍。
- [ ] 不实现模板、尺寸预设、历史作品、个人中心、管理后台的实际业务；不创建 `templates`、`size_presets`、`material_assets` 表。
