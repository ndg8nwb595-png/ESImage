# 02: 参数面板、商品名称校验与参数快照

**What to build:** 用户在右侧参数面板填写商品名称、风格，看到固定尺寸 1000×1000；商品名称为空或超长时点击生成会弹窗提示并聚焦输入框，不发送任何网络请求；商品名称未填时聊天输入框禁用，填写后聊天输入框与生成按钮同时可用。参数在未创建会话时存入草稿键，会话创建后迁移到按会话的 localStorage 键，刷新可恢复；生成时把当前参数作为快照提交。

**Blocked by:** 01（工作台骨架、最小数据表与演示配置）

**Status:** ready-for-agent

- [ ] 商品名称输入框去除首尾空格后必须为 1~60 个字符；纯空格视为未填写；输入框限制最大 60 字符，粘贴超长时截断并提示「商品名称不能超过 60 个字符」。
- [ ] 商品名称为空时点击「生成示例图」：弹窗「请先填写商品名称」，焦点移动到商品名称输入框，网络面板无任何请求。
- [ ] 商品名称超过 60 字符时点击生成：提示「商品名称不能超过 60 个字符」，聚焦输入框，不发送请求。
- [ ] 商品名称未填时聊天输入框禁用，占位文案「请先填写商品名称后再开始对话」；填写后聊天输入框与「生成示例图」按钮同时可用。
- [ ] 风格为自由文本选填，去除首尾空格后 1~50 字符；纯空格视为未填写；超长截断并提示，不阻塞生成。
- [ ] 尺寸固定展示 1000×1000；最小 demo 不提供平台预设下拉与自定义宽高编辑。
- [ ] 参数写入 `esimage_workspace_params_draft`（尚未创建会话）或 `esimage_workspace_params_{session_id}`（会话已创建）；会话创建后把草稿内容迁移到会话键并删除草稿键。
- [ ] 刷新页面后按当前会话恢复参数；新建会话参数为空，不继承上一会话内容。
- [ ] 生成时提交商品名称、风格文本、宽高、`template_id=null`、`upload_ids`、`requirement_summary` 的快照；后端按商品名称 1~60、风格 1~50、宽高正整数做二次校验。
- [ ] 生成过程中修改前端参数不影响已提交批次的快照。
- [ ] 前端校验只是第一道防线；后端对商品名称与参数格式的校验失败返回 10002 / 10004 / 10003。
