# 03: 商品图上传、恢复与排序

**What to build:** 用户可以通过点击或拖拽上传 0~5 张商品图，上传后看到缩略图网格，第一张标记「主参考图」；支持预览、删除、替换、拖动排序。格式、大小、数量不合法时前端提示且不发请求；后端做二次校验并限制该用户「未绑定会话且 active」的上传总数不超过 5 张。上传图 ID 存入 localStorage，刷新后能恢复缩略图；不上传商品图也允许生成。

**Blocked by:** 02（参数面板、商品名称校验与参数快照）

**Status:** ready-for-agent

- [ ] 支持点击选择文件与拖拽上传；单次与累计均不超过 5 张；超过时提示「最多上传 5 张商品图」且不发请求。
- [ ] 仅支持 JPG / JPEG / PNG / WEBP；格式不符提示「仅支持 JPG、PNG、WEBP 格式」，不发请求。
- [ ] 单张 ≤10MB；超出提示「单张图片不能超过 10MB」，不发请求。
- [ ] 上传成功后展示缩略图网格，第一张显示「主参考图」；每张支持预览、删除、替换、拖动排序。
- [ ] 排序仅在前端维护；点击生成时按 `upload_ids` 的提交顺序写回 `sort_order`；不提供单独的排序保存接口。
- [ ] 后端二次校验 MIME、扩展名、大小、可解码性；该用户「`session_id IS NULL` 且 `status='active'`」的上传总数新增后超过 5 张时返回 30006「最多上传 5 张商品图」。
- [ ] 上传接口返回 `upload_id`、原图与缩略图地址、宽高、大小；前端把 `upload_id` 存入 `esimage_workspace_upload_ids_draft` 或 `esimage_workspace_upload_ids_{session_id}`。
- [ ] 刷新后按 localStorage 中的 `upload_id` 调用 `GET /uploads/{upload_id}` 恢复缩略图、排序与元数据；已删除或不属于当前用户的返回 30014。
- [ ] 删除上传图只从当前创作中移除，后端软删除 `status=deleted`，不影响已生成记录中的引用。
- [ ] 上传中显示单张进度；失败可单张重试，提示「上传失败，请重试」。
- [ ] 未上传商品图时允许生成，走纯文生图（最小 demo 生成占位图）；生成时后端把本次使用的上传图回填 `session_id` 并释放未绑定名额。
- [ ] 上传图必须属于当前用户、状态 `active`，且未绑定其他会话；不满足时生成接口返回 30006。
