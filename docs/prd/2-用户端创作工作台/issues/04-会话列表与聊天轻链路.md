# 04: 会话列表与聊天轻链路

**What to build:** 左侧会话列表展示当前用户的活跃会话，按最后消息时间倒序，当前会话高亮；点击「新建会话」进入空会话草稿，不提前写库；发送第一条消息或首次生成时由后端在同一事务内创建会话并按规则自动命名。用户发送消息后气泡立即上屏，Agent 回复通过 SSE 流式展示，只显示规划 Agent 与商品理解 Agent 的状态；聊天只更新需求摘要，不触发生成。

**Blocked by:** 02（参数面板、商品名称校验与参数快照）

**Status:** ready-for-agent

- [ ] 会话列表只展示当前用户 `status=active` 的会话，按 `last_message_at` 倒序；每项展示标题、最后消息摘要（最多 30 字）、时间；当前会话高亮。
- [ ] 点击「新建会话」清空聊天区与结果区，进入空会话草稿；不调用创建会话接口、不写数据库；若当前会话没有消息与生成，允许直接切换，不产生空会话。
- [ ] 首条消息调用 `POST /sessions/messages`（`session_id=null`），后端在同一事务内创建会话并写入首条消息；`meta` 事件返回新建的 `session_id`。
- [ ] 用户消息发送后立即上屏，状态为「发送中」；SSE 返回 `delta` 时逐字追加 Agent 回复，显示规划 Agent / 商品理解 Agent 状态，完成后更新为「已完成」。
- [ ] 每条聊天消息只调用规划 Agent 与商品理解 Agent，不调用文案、提示词、生图、审核等 Agent，不创建生成批次。
- [ ] `client_message_id` 幂等：重复提交返回已保存消息，不重复调用模型；断线自动重试最多 2 次，使用同一 `client_message_id`，不产生重复消息。
- [ ] 自动命名：首条用户消息存在时取前 20 个字符；首条动作是生成时取商品名称（截断到 50）；都不可用时为「未命名会话」；用户重命名后不再自动覆盖（重命名接口不在本切片，仅保留规则）。
- [ ] 商品名称未填时聊天输入框禁用；填写后可用；空消息、超过 2000 字符禁止发送（前端拦截，后端返回 10002 / 10004）。
- [ ] 用户未填写风格时，Agent 回复列出 3~5 个适合该商品的风格建议；用户可用自然语言选择或自行补充。
- [ ] 每次聊天后更新会话 `requirement_summary`，并在 `done` 事件返回；生成示例图时随参数一起提交给全链路。
- [ ] 切换会话加载该会话的消息分页、需求摘要与最近批次；会话不存在或不属于当前用户返回 30013。
- [ ] 聊天消息与 Agent 调用记录在生成过程中落库，断线后可查询；`agent_runs` 记录 `planner` 与 `product_understanding` 的状态、Token、耗时与错误信息（demo 可为 0）。
- [ ] 未配置文本模型时返回固定演示回复与最小需求摘要；配置了 `text_model` 时可接真实模型，SSE 事件与字段不变。
