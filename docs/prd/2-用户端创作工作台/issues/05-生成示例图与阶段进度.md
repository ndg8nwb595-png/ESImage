# 05: 生成示例图、阶段进度与示例循环

**What to build:** 商品名称校验通过后，用户点击「生成示例图」，前端提交参数快照、`upload_ids`、`session_id`、`template_id=null` 与需求摘要；后端创建 `sample` 批次并返回 `batch_id` 与会话信息，结果区按阶段展示进度，最终展示 1 张示例图。用户可以「重新生成示例」或「调整参数」，示例生成期间按钮禁用；同一用户同时只允许 1 个 `queued` / `running` 批次，`sample_ready` 不占名额。

**Blocked by:** 03（商品图上传、恢复与排序）。04 不阻塞本切片；若 04 已完成，生成时读取会话中的需求摘要。

**Status:** ready-for-agent

- [ ] 商品名称校验通过后，点击「生成示例图」调用 `POST /generations/sample`，提交 `client_request_id`、`session_id`（可为空）、商品名称、风格、宽高、`template_id=null`、`upload_ids`、`requirement_summary`。
- [ ] `session_id` 为空时后端在同一事务内创建会话，标题取商品名称（截断到 50）；响应返回 `batch_id`、`session_id`、`session_title`、`status=queued`、`total_count=1`、`completed_count=0`。
- [ ] 创建批次时写入 `params_snapshot` 与需求摘要；生成过程中修改前端参数不影响已提交批次。
- [ ] 同一用户存在 `queued` / `running` 批次时，前端「生成示例图」禁用并显示「正在生成…」；后端返回 30003「已有生成任务进行中」。
- [ ] 结果区从空状态进入「示例生成中」，按阶段展示：需求理解 → 文案生成 → 提示词构建 → 图像绘制 → 质量审核 → 文字合成；阶段来自 `GET /generations/{batch_id}` 的 `stage`。
- [ ] 前端每 2 秒轮询批次状态；`sample_ready` 后停止轮询并展示示例图大图。
- [ ] 示例图完成后展示「重新生成示例」与「调整参数」两个操作；「确认并生成全套」入口由 06 切片加入。
- [ ] 点击「重新生成示例」创建新的 `sample` 批次，使用当前参数与最新需求摘要；旧批次保留可追溯，结果区只展示最新示例。
- [ ] 只有最新一次 `sample_ready` 的示例可以确认；旧示例不占并发名额，不阻塞重新生成或确认（确认校验在 06 切片落地）。
- [ ] 示例图确认前不展示下载入口；下载接口对示例图返回 30005（07 切片落地）。
- [ ] 上传图首次用于生成时回填 `session_id`，并按 `upload_ids` 顺序写回 `sort_order`。
- [ ] 切换会话或刷新后，通过会话列表的 `latest_batch_id` 或 `esimage_latest_batch_id` 恢复最近批次结果；结果区只展示当前会话的批次。
- [ ] 演示生成管线按 `queued → running → sample_ready` 推进，阶段依次写入 `product_understanding`、`copywriter`、`prompt_builder`、`image_generator`、`quality_reviewer`、`text_composition`、`done`，产出一张 1000×1000 占位 PNG；批次、图片、阶段字段与正式实现一致。
- [ ] 本切片不实现取消任务、单张重生成、重试失败张、整组 ZIP。
