# 06: 确认并生成全套与结果网格

**What to build:** 用户对最新示例满意后点击「确认并生成全套」，二次确认「确认后将生成 5 张详情图，主图会计入最终结果」；后端创建 `full` 批次，把示例图作为第 1 张主图复用、不重复生成，再生成 5 张详情图。结果区展示批量进度（如 2/6），完成后展示 1 张主图 + 5 张详情图共 6 张的网格，按序号排列。

**Blocked by:** 05（生成示例图、阶段进度与示例循环）

**Status:** ready-for-agent

- [ ] 最新示例为 `sample_ready` 时展示「确认并生成全套」按钮；点击后二次确认文案「确认后将生成 5 张详情图，主图会计入最终结果」。
- [ ] 确认调用 `POST /generations/{batch_id}/confirm`，提交 `client_request_id`；后端校验批次属于当前用户、`batch_type=sample`、状态为 `sample_ready`、是该用户最新可确认示例。
- [ ] 确认在数据库事务中执行并对示例批次加行锁；重复确认、状态不是 `sample_ready`、不是最新示例时返回 30005，前端提示并刷新批次状态。
- [ ] 创建 `full` 批次：`source_sample_batch_id` 指向示例批次，`total_count=6`、`completed_count=1`、`status=queued`；示例批次状态置 `confirmed`。
- [ ] 示例图作为全套第 1 张主图：新建 `image_type=final`、`image_role=main`、`index_no=1`、`status=success` 的图片记录，`source_image_id` 指向示例图，复用文件路径，不重复生成。
- [ ] 后端生成第 2~6 张详情图；演示管线逐张成功，`completed_count` 从 1 递增到 6，批次最终 `status=completed`、`stage=done`。
- [ ] 结果区展示批量进度条与「已完成/总数」（如 2/6、5/6）；轮询频率与 05 一致，终态停止。
- [ ] 完成后展示 6 张结果网格：第 1 张主图、第 2~6 张详情图，按 `index` 升序；每张展示缩略图、序号、状态角标。
- [ ] 全套批次完成后，6 张 `final` 成功图的 `is_history_visible` 置为 `true`；示例图与失败/取消半成品不可见。
- [ ] 确认时被确认的 `sample_ready` 示例批次不参与并发校验；当前用户已有其他 `queued` / `running` 批次时返回 30003。
- [ ] 相同 `client_request_id` 重复提交返回已创建的全套批次，不重复创建。
- [ ] 本切片不实现整组 ZIP、单张重生成、重试失败张、取消任务；结果区不展示这些入口。
