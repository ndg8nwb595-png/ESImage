# 07: 结果预览与单张下载

**What to build:** 用户点击结果区的缩略图可以打开大图预览并关闭；正式图（含确认后的示例图）可以单张下载 PNG，文件名按「商品名称_主图/详情图_序号_时间戳」生成，非法字符替换为下划线。示例图在确认前只可预览、不可下载；失败图、取消半成品不可下载。下载需要登录态与 `user.history` 权限。

**Blocked by:** 06（确认并生成全套与结果网格）

**Status:** ready-for-agent

- [ ] 示例图与正式图的缩略图均可点击打开大图弹层；弹层展示原图，支持适应屏幕与关闭；上一张/下一张、100% 缩放不在最小 demo 内。
- [ ] 大图预览通过 `GET /images/{image_id}/content` 读取，带 `Authorization`，转 `blob:` URL 展示；不在 `<img src>` 中暴露 token。
- [ ] 正式图（`image_type=final`、`status=success`、`is_history_visible=true`、批次 `completed` 或 `partially_failed`）提供「下载这张」入口，调用 `GET /images/{image_id}/download`。
- [ ] 下载文件为 PNG，文件名为 `{商品名称}_{主图|详情图}_{序号}_{yyyyMMddHHmmss}.png`；商品名称中的文件名非法字符替换为下划线。
- [ ] 示例图确认前不展示下载入口；即使直接调用下载接口，后端也返回 30005「示例图确认前不可下载」。
- [ ] 失败图、取消任务半成品、`superseded` 旧图不提供下载入口；接口返回 30005。
- [ ] 下载接口校验归属与 `user.history` 权限；不存在或不属于当前用户返回 30014，缺少权限返回 403 `20005`。
- [ ] 下载使用 `fetch` + `Authorization` 获取文件流，从 `Content-Disposition` 解析文件名；解析失败时按上述规则在前端拼装；用临时 `<a download>` 保存并释放 blob URL。
- [ ] 下载失败提示「下载失败，请稍后重试」；图片加载失败显示占位图与「图片加载失败」。
- [ ] 登录过期（401 `20002` / `20003`）时清除 token 并跳转登录；无权限（403 `20005`）时提示或跳转 `/403`。
- [ ] 本切片不实现整组 ZIP 下载与 `manifest.csv`。
