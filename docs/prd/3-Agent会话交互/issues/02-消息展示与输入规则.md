# 02: 消息展示、状态与输入规则

**What to build:** 聊天区能正确区分并渲染用户文本、Agent 文本与系统通知。用户消息保留换行且不解析 Markdown；Agent 消息支持基础 Markdown 白名单，原始 HTML 不被渲染，链接只允许 `http/https` 且新窗口打开，并显示「规划 Agent」「商品理解 Agent」标签与本地时间。消息具备发送中、流式接收中、已完成、失败可重试与本地中止五种展示状态。输入框按商品名称、长度、空消息、回复中禁用等规则拦截发送，聊天区不提供图片上传，粘贴图片被拦截并引导到右侧商品图区域。

**Blocked by:** 2 号 demo 04（会话列表与聊天轻链路）

**Status:** ready-for-agent

- [ ] 用户消息显示在右侧气泡，保留换行，不把 Markdown 语法渲染成格式；超长内容在气泡内换行，不撑破聊天栏。
- [ ] Agent 消息显示在左侧气泡，支持加粗、斜体、有序列表、无序列表、换行与行内代码；其他 Markdown 语法按普通文本展示。
- [ ] Agent 消息中的原始 HTML 以文本转义显示，不执行脚本、不加载外部资源，防止 XSS。
- [ ] Agent 消息中的链接仅 `http/https` 可点击，点击后新窗口打开；`javascript:`、`data:` 等协议不生成可点击链接。
- [ ] Agent 消息显示 Agent 名称标签：「规划 Agent」（`planner`）与「商品理解 Agent」（`product_understanding`）；同一回复经两个 Agent 时，标签取最后产生文本的 Agent。
- [ ] 系统通知居中显示、灰底；`role=system` 的消息按 `content_type` 渲染，用于「示例图已生成」「任务失败」等提示。
- [ ] 消息时间按本地时区展示，悬停显示完整时间。
- [ ] 发送后用户气泡立即上屏并显示「发送中」loading；SSE `delta` 到达时 Agent 气泡逐字追加并显示闪烁光标；`done` 后光标消失。
- [ ] 发送失败时气泡下方显示「发送失败，点击重试」；点击重试复用同一个 `client_message_id`，不产生重复消息。
- [ ] 请求被前端中止或页面离开导致未收到 `done` 时，本地展示「已停止生成」；刷新后按数据库中的实际状态展示。
- [ ] 商品名称未填时输入框禁用，占位文案「请先填写商品名称后再开始对话」；填写后可输入。
- [ ] 去除首尾空格后为空的消息阻止发送并提示「请输入内容」；超过 2000 个字符阻止发送并提示「消息不能超过 2000 个字符」，聚焦输入框。
- [ ] Enter 发送、Shift + Enter 换行；输入法组合输入期间按 Enter 不发送。
- [ ] 当前回复未结束时发送按钮禁用，提示「正在回复中，请稍候」；回复结束后恢复。
- [ ] 聊天区不提供图片上传按钮；粘贴图片时拦截并提示「请在右侧商品图区域上传图片」。
- [ ] 后端对空消息与超长消息分别返回 10002 / 10004，前端展示统一错误提示，不把失败消息当作已发送。
- [ ] 前端校验只是第一道防线；任何发送路径都不能创建生成批次或生成图片。
- [ ] 后端 pytest、前端 vitest 覆盖 Markdown 白名单、HTML 转义、消息状态与输入拦截；每个测试步骤输出中文日志。
