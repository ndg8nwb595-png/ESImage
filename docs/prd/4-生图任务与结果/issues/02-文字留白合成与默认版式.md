# 02: 文字留白合成与默认版式

**What to build:** 后端接收基础图与每张图的文案块，按 PRD §7.4 的默认版式生成 `layout_instruction`，用内置可商用中文字体把标题与卖点合成到图上，输出与原图同尺寸的 PNG。标题居中放在上方 15% 区域，卖点放在下方 20% 区域且最多 3 条，左右安全边距 8%；深色文字配浅色底，留白不足时加半透明白底保证可读。文案超长时自动缩小字号到下限，仍超出则截断并记录警告，不阻塞出图。合成失败时返回「文字合成失败」及具体原因。

**Blocked by:** 01（生成数据模型、配置种子与 Agent 运行时）

**Status:** ready-for-agent

- [ ] 输入契约与 PRD §7.2 一致：`canvas{width,height}` 与 `blocks[]`，`blocks` 支持 `title` 与 `selling_points` 两类；输出为 PNG 文件路径与元数据。
- [ ] 默认版式：标题区位于画布上方 15% 区域并居中；卖点区位于下方 20% 区域，最多渲染 3 条；左右边距为画布宽度的 8%。
- [ ] 标题与卖点使用内置中文字体；字体文件缺失或加载失败时返回「文字合成失败」，不产出半成品。
- [ ] 深色文字可读；当基础图对应区域亮度不足时叠加半透明白色底，不改变文字内容与位置契约。
- [ ] 文案超长时按比例缩小字号至下限；仍超出则截断并在合成结果中记录警告列表，出图继续。
- [ ] 卖点超过 3 条时只渲染前 3 条，并记录警告；空标题或空卖点不渲染对应区块。
- [ ] 输出尺寸与 `canvas` 一致；输出格式为 PNG；合成结果可被生成管线直接作为最终图使用。
- [ ] 合成模块可独立测试：给定一张测试底图与样例文案，执行后可用肉眼检查中文正确、版式符合上述规则。
- [ ] 图片损坏、画布尺寸非法、字体缺失、写文件失败时返回明确失败原因，不抛出未处理异常。
- [ ] 本切片不接入 Agent 调用、不创建批次、不改变 2 号 demo 的接口；只交付可被 03/04/07 调用的合成能力与默认版式。
