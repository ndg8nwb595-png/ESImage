# 03: 示例批次真实全链路

**What to build:** 用户点击「生成示例图」后，Worker 用真实豆包执行完整 Agent 链路：规划 → 商品理解（含素材检索）→ 文案 → 提示词 → 生图执行 → 生成图内容审核 → 质量审核 →（不通过时）修复 → 生图 → 质量审核复检 → 平台规范 → 文字合成，最终产出 1 张带正确中文标题与卖点的示例图。规划、商品理解、文案、提示词四个 Agent 覆盖全部 6 张图（1 主图 + 5 详情图），但示例批次只渲染第 1 张主图。批次阶段随执行推进，成功置 `sample_ready`；核心 Agent 失败置 `failed` 并记录阶段与错误；非核心 Agent 跳过并标记；生成图被内容审核拦截时该张失败，不自动重试。示例图可反复重新生成，每次创建新的 `sample` 批次，旧批次保留。

**Blocked by:** 02（文字留白合成与默认版式）、2 号 demo 05（生成示例图与阶段进度）

**Status:** ready-for-agent

- [ ] 沿用 2 号 demo 的 `POST /generations/sample` 请求与响应契约；`template_id` 允许为空或指向启用模板，传入时把模板名称、风格文案、提示词模板、版式参考写入 `params_snapshot`。
- [ ] 创建示例批次时在同一事务内创建 1 条 `index=1`、`image_role=main`、`image_type=sample`、`status=pending` 的图片记录；批次 `total_count=1`、`completed_count=0`、`status=queued`、`stage=null`。
- [ ] Worker 取出批次后置 `running`，阶段依次更新为 `planner`、`product_understanding`、`copywriter`、`prompt_builder`、`image_generator`、`quality_reviewer`、`platform_rule`、`text_composition`、`done`；进入每个阶段前更新 `generation_batches.stage`。
- [ ] 规划 Agent 输出 6 项计划：1 个 `role=main` + 5 个 `role=detail`，序号 1~6，主题动态生成且不重复；输出写入 `agent_runs.output_full`。
- [ ] 商品理解 Agent 读取商品名称、上传商品图、需求摘要与聊天摘要，调用素材检索工具从启用素材中选出候选，输出商品画像与 `material_ids`；素材检索不单独写 `agent_runs`；未上传商品图时输出标注「无实物参考」。
- [ ] 文案 Agent 输出全部 6 张图的简体中文文案块；标题 6~12 字、每条卖点 4~10 字；不生成价格、促销倒计时等用户未提供的信息。
- [ ] 提示词 Agent 输出全部 6 张图的提示词、负面提示词、留白比例、参考素材与模型参数；提示词显式要求留白，不把大段中文文案写进提示词。
- [ ] 生图执行 Agent 只对 `index=1` 调用豆包 Seedream：有上传图走图生图，无上传图走文生图；单张超时 120 秒；失败最多尝试 2 次，2 次失败批次立即 `failed`。
- [ ] 生成图在质量审核前送豆包内容审核；被拦截时该张 `failed`，原因「内容未通过审核，请调整描述或更换商品图」，不自动重试；审核接口自身失败按生图失败处理并进入 2 次尝试。
- [ ] 质量审核 Agent 使用 `DOUBAO_VISION_MODEL` 检查商品变形、留白可用性、违规内容；`vision_model` 为空或 Agent 连续 10 次失败时跳过并标记「未校验」，继续后续流程。
- [ ] 质量审核 `passed=false` 时进入修复 Agent：最多修复 1 次，输出修正后的提示词，重新生图并复检；复检仍不通过则该张 `failed`，原因「质量问题未通过」；修复 Agent 连续 10 次失败时跳过并标记「未修复」，该张按未通过处理。
- [ ] 平台规范 Agent 读取 `platform_rule` 系统提示词中的 `{{platform_rules}}`，检查尺寸、违禁词、类目规则；不通过时该张 `failed`，提示用户调整文案或参数，不自动重试；Agent 连续 10 次失败时跳过并标记「未校验」，继续文字合成。
- [ ] 文字合成使用 02 的默认版式与默认 `layout_instruction`，把标题与卖点合成到基础图；合成失败该张 `failed`，原因「文字合成失败」。
- [ ] 成功后写入 `file_path`、`thumbnail_path`、`width`、`height`、最终 `prompt`、`negative_prompt`、`model_name`、`latency_ms` 与 Token；图片 `status=success`，批次 `completed_count=1`、`status=sample_ready`、`finished_at` 写入。
- [ ] 核心 Agent（规划、商品理解、文案、提示词）连续 10 次失败时批次 `failed`，记录失败阶段、错误信息与 `finished_at`；前端能从 `GET /generations/{batch_id}` 看到卡点。
- [ ] 每次 Agent 调用（含每次重试）写 `agent_runs`；成功路径至少包含 planner、product_understanding、copywriter、prompt_builder、image_generator、quality_reviewer、platform_rule 七类记录，修复分支额外包含 repairer 与第二次 image_generator/quality_reviewer。
- [ ] 示例批次 `sample_ready` 后不占并发名额；再次点击「重新生成示例」创建新的 `sample` 批次，旧批次状态保留，结果区只展示最新示例。
- [ ] `GET /generations/{batch_id}` 返回阶段、图片状态、`content_url` 与 `thumbnail_url`；轮询在 `sample_ready` / `failed` / `cancelled` 时停止。
- [ ] 本切片不实现全套批次、取消、单张重试、ZIP；示例图确认前不可下载，下载拦截由后续切片保持。
