# 04: 确认全套与详情图生成

**What to build:** 用户确认最新的 `sample_ready` 示例后，系统创建 `full` 批次：把示例图直接复用为第 1 张正式主图，不重复生成；复用示例批次的规划、商品理解、文案、提示词四个 Agent 的完整输出，串行生成第 2~6 张详情图。每张详情图执行生图 → 生成图内容审核 → 质量审核（含修复复检）→ 平台规范 → 文字合成。`completed_count` 从 1 递增到 6，批次按实际结果置 `completed` / `partially_failed` / `failed`；全套完成后，成功正式图进入历史作品。

**Blocked by:** 03（示例批次真实全链路）、2 号 demo 06（确认并生成全套与结果网格）

**Status:** ready-for-agent

- [ ] 沿用 2 号 demo 的 `POST /generations/{batch_id}/confirm` 请求与响应契约；确认在事务中对示例批次加行锁，校验归属、`batch_type=sample`、状态 `sample_ready`、是该用户最新可确认示例；重复确认或状态不符返回 30005。
- [ ] 创建 `full` 批次：`source_sample_batch_id` 指向示例批次，`total_count=6`、`completed_count=1`、`status=queued`、`stage=null`；复制示例批次的 `params_snapshot` 与 `requirement_summary`；示例批次置 `confirmed`。
- [ ] 为示例图新建一条 `generated_images` 记录：`batch_id=full`、`image_type=final`、`image_role=main`、`index_no=1`、`attempt_no=1`、`status=success`、`source_image_id=示例图`，复用示例图的 `file_path`、`thumbnail_path`、`width`、`height`，不重新调用生图。
- [ ] 创建 `index=2~6`、`image_role=detail`、`image_type=final`、`status=pending` 的图片记录，共 5 条，供结果区完整展示 6 个位置。
- [ ] 全套批次不再调用规划、商品理解、文案、提示词四个 Agent；Worker 从被确认示例批次的 `agent_runs.output_full` 读取这四类输出；缺失或不完整时批次 `failed`，错误信息说明「示例结果不完整」。
- [ ] 按规划输出的顺序逐张串行生成第 2~6 张：同一批次内不并行；每张开始前把批次 `stage` 置 `image_generator`，随后进入 `quality_reviewer`、`platform_rule`、`text_composition`。
- [ ] 每张详情图使用示例批次对应序号的计划主题、文案块与提示词；生图、内容审核、质量审核/修复、平台规范、文字合成的规则与 03 一致。
- [ ] 单张成功后写入文件、缩略图、尺寸、模型名、耗时、Token，图片 `status=success`，`completed_count` 加 1；单张非生图原因失败时该张 `failed` 并继续下一张。
- [ ] 全部结束：6 张成功 → `completed`；部分成功 → `partially_failed`；全部失败 → `failed`；写入 `finished_at` 与批次错误摘要。
- [ ] 批次进入 `completed` 或 `partially_failed` 后，6 张 `image_type=final`、`status=success` 的当前图 `is_history_visible=true`；失败图、`superseded` 图、示例图保持 `false`。
- [ ] `GET /generations/{batch_id}` 返回 `completed_count` 从 1 到 6 的进度、当前 `stage`、每张图的序号/角色/状态/预览地址；前端结果网格按 `index` 升序展示 1 主图 + 5 详情图。
- [ ] 确认时被确认的 `sample_ready` 示例批次不参与并发校验；用户已有其他 `queued` / `running` 批次时返回 30003。
- [ ] 相同 `client_request_id` 重复提交返回已创建的全套批次，不重复创建、不重复投递。
- [ ] 本切片在正常路径下交付 6 张完整结果；失败注入、整批超时、取消、单张重试、ZIP 由后续切片交付。
