# 05: 失败重试、降级与部分失败

**What to build:** 把 PRD §8.1、§8.2、§8.5 的失败策略完整落到生成管线：非生图 Agent 连续失败重试 10 次并指数退避；核心 Agent 仍失败则批次失败并记录卡点；生图每张最多 2 次，2 次失败整批立即失败且不再生成后续张；非核心 Agent（质量审核、修复、平台规范）仍失败则跳过并标记「未校验」「未修复」，流程继续；非生图原因导致的单张失败只标记该张，其余继续，批次最终为 `partially_failed`；整批 30 分钟超时后未完成部分标记失败，并按生图是否完成决定 `failed` 或 `partially_failed`。所有失败原因写回批次或图片，前端能看到卡点阶段。

**Blocked by:** 04（确认全套与详情图生成）

**Status:** ready-for-agent

- [ ] 非生图 Agent 单次失败按 1、2、4、8、16、30、30、30、30、30 秒退避，共 10 次；每次尝试写一条 `agent_runs`，最终失败的那次记录 `status=failed` 与 `error_message`。
- [ ] 核心 Agent（规划、商品理解、文案、提示词）10 次仍失败：批次 `failed`，写入失败阶段、错误信息、`finished_at`；已完成的图片保留；未开始的图片标记 `failed`，原因「批次已失败，未生成」。
- [ ] 生图执行 Agent 每张最多 2 次；2 次均失败时批次立即 `failed`，不再生成后续张；后续未开始的图片标记 `failed`，原因「批次已失败，未生成」；批次错误信息记录「生图失败」与模型错误。
- [ ] 非核心 Agent 10 次仍失败：质量审核/平台规范跳过并标记「未校验」，修复跳过并标记「未修复」；对应 `agent_runs` 写 `status=skipped`，流程继续，不因该 Agent 失败使批次失败。
- [ ] 质量审核判定不通过时执行修复 1 次并重生图、复检；复检仍不通过该张 `failed`，原因「质量问题未通过」；修复 Agent 跳过时该张按未通过处理，原因包含「未修复」。
- [ ] 生成图内容审核拦截：该张 `failed`，原因「内容未通过审核，请调整描述或更换商品图」，不自动重试；全套批次继续下一张。
- [ ] 平台规范不通过：该张 `failed`，原因包含尺寸、违禁词或类目规则的具体问题，不自动重试；全套批次继续。
- [ ] 文字合成失败：该张 `failed`，原因「文字合成失败」；全套批次继续。
- [ ] 非生图原因的单张失败不改变其他张的生成；批次结束时按成功张数置 `completed`（全部成功）、`partially_failed`（部分成功）、`failed`（全部失败）。
- [ ] 整批超时默认 1800 秒，可由 `BATCH_TIMEOUT_SECONDS` 缩短用于演示；超时后停止创建新图片任务，未完成图片标记 `failed`，原因「批次超时」；生图环节未完成则批次 `failed`，否则按实际结果 `partially_failed`。
- [ ] 批次与图片的 `error_message` 可被 `GET /generations/{batch_id}` 读取；前端在结果区展示失败张状态、原因与重试入口，并展示批次卡点阶段。
- [ ] 提供仅测试环境可用的故障注入开关（环境变量或测试替身），可分别模拟核心 Agent 连续失败、生图连续失败、质量审核不通过、平台规范不通过、合成失败与超时；生产接口不暴露故障注入参数。
- [ ] 本切片不实现取消、单张重试接口、ZIP；失败张的重试入口由 07 落地，取消由 06 落地。
