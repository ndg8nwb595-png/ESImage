# 06: 取消任务

**What to build:** 用户可以对 `queued` / `running` / `sample_ready` 的示例批次，以及 `queued` / `running` 的全套批次发起取消。后端在事务中校验归属与状态，把批次置 `cancelled` 并写 `finished_at`；Worker 在下一个检查点停止创建新的图片任务。已在生成中的单张允许完成，但结果不进入历史作品；已成功的图片保留在后台记录中并标记为取消任务产物。取消需要前端二次确认；取消后前端停止轮询并展示取消态。重复取消按幂等处理，不报错。

**Blocked by:** 04（确认全套与详情图生成）

**Status:** ready-for-agent

- [ ] `POST /api/v1/generations/{batch_id}/cancel` 仅允许当前用户操作自己的批次；越权或不存在返回 404 `30004`。
- [ ] 示例批次允许从 `queued`、`running`、`sample_ready` 取消；全套批次允许从 `queued`、`running` 取消；其他状态返回 409 `30005`，提示「当前批次状态不允许取消」。
- [ ] 取消在数据库事务中执行并对批次加行锁；成功后 `status=cancelled`、`finished_at` 写入，返回批次 ID、状态与结束时间。
- [ ] 已取消的批次再次取消返回 200 与当前取消态，不重复写结束时间，不产生错误。
- [ ] Worker 在每次 Agent 调用前、每张图开始前、每张图完成后检查批次状态；发现 `cancelled` 后不再创建新的图片任务，不再进入下一张。
- [ ] 取消时已在生成中的单张允许完成；完成后图片记录保留，`is_history_visible=false`；批次保持 `cancelled`，不因该张完成而被改回其他终态。
- [ ] 取消时尚未开始的图片记录置 `cancelled`；已成功的图片保留原状态但 `is_history_visible=false`。
- [ ] 取消后的批次与图片不出现在历史作品；单张下载与整组下载对该批次返回 409 `30005`。
- [ ] 前端在可取消状态下展示「取消生成」入口；点击后二次确认，确认后调用取消接口；取消成功后停止轮询，结果区展示「已取消」，保留已完成的图片仅供当前页面查看、不提供下载。
- [ ] 取消与确认、重试、重生成互斥：确认或单张操作与取消并发时，以行锁后的最终状态为准，非法操作返回 `30005`。
- [ ] 取消不删除任何已产生的图片、文件或 `agent_runs` 记录；后台追溯仍可查询。
- [ ] 本切片不实现批次级重新生成、历史作品入口与 ZIP；取消后的半成品只保留在后台与当前结果区。
