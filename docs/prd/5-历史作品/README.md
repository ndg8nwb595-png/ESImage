# 5-历史作品：最小实现 demo

| 项目 | 内容 |
| --- | --- |
| 上游 PRD | [`5-历史作品prd.md`](./5-历史作品prd.md) |
| 目标 | 用最小范围跑通「历史列表 → 批次详情 → 大图预览 → 单张下载 → 整组 ZIP → 归档读取」的只读端到端演示 |
| 任务形式 | 5 个垂直切片，按依赖顺序编号，存放在 `issues/` |
| 接口文档 | [`接口文档-历史作品最小demo.md`](./接口文档-历史作品最小demo.md) |

> 本目录只覆盖 5 号 PRD 中与「历史作品最小演示」直接相关的集合，不代表 5 号 PRD 的全部验收项。生成侧的数据、批次状态与图片文件由 2 号 demo 提供；历史页只做读取、预览与下载，不提供任何写操作。

## 1. 最小 demo 范围

### 1.1 做

- 历史列表：以 `full` 批次为卡片单位，展示封面缩略图、商品名称、图片构成、成功张数、生成时间；按批次 `created_at` 倒序，每页 20 条。
- 展示范围严格按 5 号 §3.1：本人、`full` 批次、`completed` / `partially_failed`、`image_type=final`、`status=success`、`is_history_visible=true`。
- 空状态、骨架屏、加载失败重试。
- 批次详情：`/history/{batch_id}` 独立路由，支持刷新与浏览器回退；顶部展示商品名称、图片构成、尺寸、风格、生成时间、成功张数；成功图片按 `index` 升序网格。
- 大图预览：原图弹层、适应屏幕、100%、上一张/下一张、序号与尺寸、关闭返回网格。
- 单张下载：PNG，文件名 `{商品名称}_{主图|详情图}_{序号}_{yyyyMMddHHmmss}.png`，非法字符替换为下划线。
- 整组下载：批次详情页内同步流式返回 ZIP；ZIP 仅含成功图片，`manifest.csv` 记录全部 6 张（含失败行）。
- 归档读取：`archived_at` 非空的图片从 `archive/` 前缀读取，仍可预览、单张下载与进入 ZIP；读取慢与不可用有提示。
- 只读与权限：仅本人数据；未登录跳登录；缺少 `user.history` 返回 403；越权访问他人批次返回 403。

### 1.2 不做

- 删除、编辑、重命名历史作品。
- 收藏、分组、标签、分享链接、公开访问。
- 关键词搜索、时间/类型筛选（5 号 PRD 已明确不做）。
- 展示提示词与完整生成参数。
- 管理员/超管通过该页面查看用户作品（统一走管理后台「内容追溯」，属于 7 号 PRD）。
- 每日 03:00 的 5 年归档调度任务、归档后恢复（只实现归档后的读取）。
- ZIP 异步打包任务、任务中心、下载记录页。
- 补生成、重试失败张、从历史页跳回原会话的深链（PRD 只要求「用户需回原会话重试」，不要求历史页提供入口）。
- 历史页内的 100% 拖拽平移、旋转、图片编辑。
- 手机端适配。

### 1.3 相对 PRD 的最小化取舍

| PRD 要求 | 最小 demo 处理 | 原因 / 影响 |
| --- | --- | --- |
| 每页 20 条 | 固定 20，只接受 `page`，不开放 `page_size` | 与 5 号 §2.1 一致；避免把全站分页参数带进历史页 |
| 5 年归档每日 03:00 执行 | 不做调度任务；用种子数据模拟 `archived_at` 与 `archive/` 前缀 | 只演示归档后的读取与下载；正式实现按 10 号 §7.2 补任务 |
| 缩略图长期保留在热存储 | 保持；新增缩略图读取接口 | 2 号 demo 只返回 `thumbnail_url`，未定义该路径 |
| 归档读取超时由部署配置决定 | 读取超时用 `ARCHIVE_READ_TIMEOUT_SECONDS`，默认 60 秒 | 与 5 号 §10 待确认项一致；演示可缩短 |
| 部分失败批次 | 2 号演示管线只产出 `completed`，部分失败批次由种子夹具提供 | 完整失败链路属于 4 号 demo 05，不在本目录重做 |
| 大图预览支持适应屏幕、100%、上一张/下一张 | 全部实现；不实现拖拽平移、旋转 | 满足 5 号 §4.3 的可操作项 |
| 整组 ZIP 后端同步打包并流式返回 | 实现；单批最多 6 张 PNG | 与 4 号 demo 08 契约对齐，若 4 号已完成则复用而非重复实现 |
| 归档读取慢时显示「正在从归档读取…」 | 前端按请求耗时判断：超过 300ms 未返回即显示 | 详情接口不返回 `archived_at`；避免为提示新增字段 |
| 缩略图读取失败 | 显示占位图与「图片加载失败」 | 与 2 号 demo 的结果区一致 |
| 预览与缩略图权限 | `/images/{id}/content` 与 `/images/{id}/thumbnail` 同时接受 `user.history` 或 `user.generate` | 5 号要求 `user.history`，2 号 demo 已用 `user.generate`；放宽为任一权限不破坏已有调用 |
| 历史页显示生成时间 | 取批次 `created_at`，前端按本地时区精确到分钟 | 与 5 号 §2.1 一致 |

## 2. 前置与演示数据

### 2.1 前置

本目录假定以下内容已完成：

1. 「1-登录界面」最小 demo 的 01~03：工程骨架、登录闭环、登录态恢复与路由守卫。
2. 「2-用户端创作工作台」最小 demo 的 06：确认全套后产出 `full` 批次、1 主图 + 5 详情图、6 张 `final` 成功图，并置 `is_history_visible=true`。
3. 「2-用户端创作工作台」最小 demo 的 07：单张预览 `GET /images/{image_id}/content`、单张下载 `GET /images/{image_id}/download` 与文件名规则可用；历史页复用，不重复实现后端规则。

历史页不依赖 4 号 demo 的真实 8 Agent 管线；占位 PNG 足以演示列表、预览与下载。若 4 号 demo 已完成，历史页无需改动即可读取真实生成图。

### 2.2 种子数据

本目录的 01 切片需要提供可重复执行的演示种子，至少覆盖：

| 夹具 | 用途 |
| --- | --- |
| `demo_user` 的 21 个 `completed` 全套批次 | 验证每页 20 条与分页 |
| `demo_user` 的 1 个 `partially_failed` 全套批次（5 成功 + 1 失败） | 验证部分失败的成功张数、详情只展示成功图、ZIP 失败行 |
| `demo_user` 的 1 个 `sample_ready` / `confirmed` 示例批次 | 验证示例图不进历史 |
| `demo_user` 的 1 个 `failed` 全套批次 | 验证失败批次不进历史 |
| 1 个含 `superseded` 旧图的全套批次 | 验证被替代旧图不展示、不上封面 |
| 1 个 `archived_at` 非空的全套批次 | 验证归档读取、下载与 ZIP（05 切片使用） |

种子图片使用本地存储适配层与占位 PNG；归档夹具的原件放在 `archive/generated/...`，缩略图仍留在 `thumbnails/...`。

## 3. 接口总览

详细字段、错误码与文件规则见 [`接口文档-历史作品最小demo.md`](./接口文档-历史作品最小demo.md)。

| 方法 | 路径 | 权限 | 用途 | 所在 Ticket |
| --- | --- | --- | --- | --- |
| GET | `/api/v1/history` | `user.history` | 当前用户历史批次分页 | 01 |
| GET | `/api/v1/history/{batch_id}` | `user.history` | 批次详情与成功图片列表 | 02 |
| GET | `/api/v1/images/{image_id}/thumbnail` | `user.history` 或 `user.generate` | 列表封面与网格缩略图（demo 新增） | 01 / 02 |
| GET | `/api/v1/images/{image_id}/content` | `user.history` 或 `user.generate` | 大图预览（复用 2 号 demo，权限放宽） | 03 |
| GET | `/api/v1/images/{image_id}/download` | `user.history` | 单张下载（复用 2 号 demo） | 03 |
| GET | `/api/v1/batches/{batch_id}/download` | `user.history` | 整组 ZIP + `manifest.csv` | 04 |

### 3.1 明确不提供的接口

- 历史作品的删除、编辑、重命名、收藏、搜索、筛选、分享接口。
- 历史批次级或单图级的补生成、重试接口。
- 管理后台内容追溯、生成记录查询接口。
- 归档调度触发、归档恢复、下载任务查询接口。
- `GET /api/v1/history/{batch_id}/images`：批次详情已返回图片列表，不单独提供。
- `GET /api/v1/profile`、`/api/v1/admin/*`。

## 5. 验收总口径（演示脚本）

最小 demo 完成时，至少能完整演示以下路径：

1. `demo_user` 登录后点击顶部「历史作品」进入 `/history`，首屏出现骨架屏，随后展示卡片列表。
2. 卡片按生成时间倒序；每张卡片展示封面缩略图、商品名称、「1 主图 + 5 详情图」、成功张数（全成功显示「6 张」，部分失败显示「5/6 张」）与精确到分钟的时间。
3. 示例批次、失败批次、取消半成品、`superseded` 旧图均不出现在列表；滚动到分页器，第 1 页 20 条，第 2 页为剩余 1 条。
4. 清空该用户数据后刷新 → 显示空状态「还没有作品，去创作台生成第一组图吧」与「去创作」按钮，点击进入 `/workspace`。
5. 断开后端后刷新 → 显示「加载失败，点击重试」，恢复后重试成功。
6. 点击任一卡片 → 进入 `/history/{batch_id}`；刷新页面仍停留该详情；浏览器回退回到列表。顶部展示商品名称、图片构成、尺寸、风格、生成时间、成功张数。
7. 详情网格按序号升序展示全部成功图；部分失败批次只展示 5 张成功图，头部显示「成功 5 / 共 6」。
8. 点击缩略图 → 大图弹层；可切换适应屏幕/100%、上一张/下一张，显示序号与尺寸；关闭回到网格。
9. 点击「下载这张」→ 得到 PNG，文件名为 `{商品名称}_{主图|详情图}_{序号}_{yyyyMMddHHmmss}.png`；商品名称含 `/`、`:` 等字符时被替换为下划线；下载失败提示「下载失败，请稍后重试」。
10. 在批次详情点击「下载整组」→ 得到 ZIP；解压后为全部成功图片与 `manifest.csv`；部分失败批次的 ZIP 只有成功图，manifest 有 6 行且失败行带失败原因。
11. 访问归档批次详情 → 大图预览与下载可用，读取超过 300ms 时显示「正在从归档读取…」；归档文件暂时不可用时提示「文件归档中，请稍后重试」，服务端日志有错误记录。
12. 直接访问示例批次的 `/history/{batch_id}` → 批次不存在；使用 `demo_other` 的批次 ID → 403。
13. `demo_admin` 访问 `/history` 或调用 `GET /history` → 403；未登录访问 `/history` → 跳转登录页。
14. 页面不出现删除、编辑、重命名、搜索、收藏、分享入口，也不展示提示词与生成参数。

## 6. 待确认项

以下事项在接口文档中给出了 demo 默认口径，正式实现前需要与 2、4、7、9、10 号文档统一：

1. **预览与缩略图权限**：5 号要求 `user.history`，2 号 demo 的 `/images/{id}/content` 使用 `user.generate`；demo 放宽为两者任一，正式实现需确认是否统一为 `user.history` 或拆分预览/下载权限。
2. **缩略图接口**：2 号 demo 只返回 `thumbnail_url`，9 号未定义路径；demo 新增 `GET /images/{id}/thumbnail`，正式实现需写入 9 号。
3. **越权响应**：5 号要求越权访问他人批次返回 403，2 号 demo 对批次查询统一用 404 不泄露存在性；历史接口按 5 号返回 403，正式实现需确认全站口径。
4. **分页参数**：5 号固定每页 20，9 号通用分页允许 `page_size`；历史接口不开放 `page_size`，正式实现需确认是否允许用户调整。
5. **归档提示的判定方式**：demo 用 300ms 请求耗时启发式判断「正在从归档读取…」；若需精确提示，需在详情响应增加 `archived` 或 `archived_at` 字段。
6. **归档件不可用时的 ZIP 行为**：demo 只要任一图片读取失败就整体返回 30014，不返回残缺 ZIP；正式实现需确认是否跳过失败文件并在 manifest 标注。
7. **manifest.csv 细节**：demo 使用 UTF-8 BOM、中文表头、`success`/`failed` 状态、ISO 8601 生成时间；正式实现需与 4 号 demo 08 统一。
8. **封面选择**：demo 取序号最小的成功图作为封面；若首张失败则封面顺延，需产品确认是否符合预期。
9. **生成时间的取用**：列表与详情统一取批次 `created_at`；单张下载与 ZIP 文件名中的时间戳取图片 `created_at`，需与 4 号示例统一。
10. **部分失败夹具来源**：2 号演示管线不产出 `partially_failed`，demo 用种子数据；正式实现由 4 号 demo 05 提供。
11. **ZIP 实现复用**：4 号 demo 08 也实现 `GET /batches/{batch_id}/download`；两个 demo 必须共用同一契约与实现，避免分叉。
