# 01: 历史列表、分页与空态

**What to build:** 普通用户登录后点击顶部「历史作品」进入 `/history`，看到自己已完成的整套作品卡片。每张卡片以一个 `full` 批次为单位，展示封面缩略图、商品名称、图片构成、成功张数与生成时间；按批次生成时间倒序，每页 20 条。示例批次、失败批次、取消半成品、被替代旧图与其他用户的数据都不出现。没有作品时显示空状态并可跳转创作台；加载中显示骨架屏；加载失败可点击重试。

**Blocked by:** 1 号 demo 01~03（登录态与路由守卫）、2 号 demo 06（`full` 批次与 6 张正式图）

**Status:** ready-for-agent

- [ ] `GET /api/v1/history` 只返回当前用户的 `full` 批次，且批次状态为 `completed` 或 `partially_failed`；只统计 `image_type=final`、`status=success`、`is_history_visible=true` 的图片。
- [ ] 列表项包含 `batch_id`、`product_name`、`main_count`（固定 1）、`detail_count`（固定 5）、`success_count`、`total_count`、`cover_image_id`、`cover_thumbnail_url`、`created_at`；不返回提示词与生成参数。
- [ ] 封面取该批次序号最小的成功图；该图的缩略图通过 `GET /images/{image_id}/thumbnail` 读取，带登录态并以 `blob:` URL 展示。
- [ ] 排序为批次 `created_at` 倒序、`id` 倒序兜底；固定每页 20 条，只接受 `page`（默认 1）；超出范围的页码返回空 `items` 但 `total` 正确。
- [ ] 示例批次、`failed` 批次、`cancelled` 批次、`superseded` 旧图、`is_history_visible=false` 的图片均不进入列表；其他用户的批次不出现。
- [ ] 种子脚本可重复执行，至少覆盖：21 个 `completed` 批次（验证分页）、1 个 `partially_failed` 批次（5 成功 + 1 失败）、1 个 `sample_ready` / `confirmed` 示例批次、1 个 `failed` 批次、1 个含 `superseded` 旧图的批次、1 个归档批次；夹具复用 2 号 demo 的占位 PNG 生成方式。
- [ ] 前端 `/history` 替换原占位页；卡片展示封面、商品名称、「1 主图 + 5 详情图」、成功张数（全成功显示「6 张」，部分失败显示「5/6 张」）、本地时区精确到分钟的生成时间。
- [ ] 首次加载显示骨架屏；接口失败显示「加载失败，点击重试」，点击后重新请求；图片加载失败显示占位图与「图片加载失败」。
- [ ] 空数据显示「还没有作品，去创作台生成第一组图吧」与「去创作」按钮，点击跳转 `/workspace`。
- [ ] 分页器固定在列表下方，页码切换后回到列表顶部并重新请求；页大小不提供用户调整入口。
- [ ] 未登录访问 `/history` 跳转登录页；进入页面后请求返回 401 `20002` / `20003` 时清除登录态并跳登录；返回 403 `20005` 时跳 `/403`；`demo_admin` 无法访问。
- [ ] 页面不出现删除、编辑、重命名、搜索、筛选、收藏、分享入口；桌面宽度 1280px 下无横向滚动。
