# 02: 批次详情与图片网格

**What to build:** 用户点击历史卡片进入 `/history/{batch_id}`，看到该批次的完整信息与全部成功图片。详情页支持刷新与浏览器回退，顶部展示商品名称、图片构成、尺寸、风格、生成时间与成功张数；下方按序号升序展示 1 张主图与若干详情图的缩略图网格。部分失败批次只展示成功图片，不展示失败占位。

**Blocked by:** 01（历史列表、分页与空态）

**Status:** ready-for-agent

- [ ] `GET /api/v1/history/{batch_id}` 校验批次属于当前用户、`batch_type=full`、状态为 `completed` 或 `partially_failed`；否则按下方错误规则返回。
- [ ] 响应包含 `batch_id`、`product_name`、`style_text`、`width`、`height`、`main_count`、`detail_count`、`success_count`、`total_count`、`status`、`created_at` 与 `images`。
- [ ] `images` 只包含 `image_type=final`、`status=success`、`is_history_visible=true` 的图片，按 `index` 升序；每项包含 `image_id`、`index`、`image_role`、`width`、`height`、`thumbnail_url`、`content_url`、`created_at`。
- [ ] 部分失败批次只返回成功图；`success_count` 与 `total_count` 用于显示「成功 5 / 共 6」，不做失败图占位。
- [ ] 批次不存在返回 404 `30004`；批次属于他人返回 403 `20005`；批次是自己但不是 `full` 或状态不允许（如示例批次、失败批次）返回 404 `30004`。
- [ ] 卡片点击跳转 `/history/{batch_id}`；直接输入地址或刷新页面可恢复详情；浏览器回退返回列表并保留原分页。
- [ ] 顶部信息展示商品名称、图片构成、`宽 × 高`、风格（为空显示「未指定」）、批次生成时间（本地时区精确到分钟）、成功张数。
- [ ] 网格按序号排列，每张显示缩略图与序号；缩略图经 `GET /images/{image_id}/thumbnail` 读取并转 `blob:` URL。
- [ ] 缩略图加载失败显示占位图与「图片加载失败」；详情接口失败显示「加载失败，点击重试」。
- [ ] 详情页不展示提示词、生成参数、Prompt、模型名与 Token；不出现删除、编辑、重命名、补生成、重试入口。
- [ ] 未登录或登录过期按 01 的规则跳转登录；403 跳 `/403`；404 显示「批次不存在」并提供返回历史列表入口。
