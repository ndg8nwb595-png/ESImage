# 03: 大图预览与单张下载

**What to build:** 用户在批次详情网格点击任一缩略图，打开大图弹层查看原图；弹层支持适应屏幕、100%、上一张/下一张，显示序号与尺寸，关闭后回到网格。弹层内提供「下载这张」，保存为 PNG，文件名按「商品名称_主图/详情图_序号_时间戳」生成，商品名称中的非法字符替换为下划线；下载失败有提示。

**Blocked by:** 02（批次详情与图片网格）、2 号 demo 07（预览与单张下载基线）

**Status:** ready-for-agent

- [ ] 点击缩略图打开弹层，通过 `GET /images/{image_id}/content` 带 `Authorization` 读取原图并转 `blob:` URL；不把 token 放进 `<img src>` 或查询串。
- [ ] 弹层支持「适应屏幕」与「100%」两种查看方式；100% 时超出容器可滚动，不实现拖拽平移与旋转。
- [ ] 上一张/下一张只在该批次成功图片之间切换，边界处禁用对应按钮；弹层显示当前序号与图片尺寸。
- [ ] 关闭弹层回到网格，网格滚动位置保持；按 Esc 等价于关闭。
- [ ] 弹层内「下载这张」调用 `GET /images/{image_id}/download`，使用 `fetch` + `Authorization` 获取文件流，从 `Content-Disposition` 解析文件名，解析失败时按规则在前端拼装。
- [ ] 下载文件为 PNG，文件名为 `{商品名称}_{主图|详情图}_{序号}_{yyyyMMddHHmmss}.png`；时间戳取图片 `created_at`，按本地时区格式化。
- [ ] 商品名称中的 Windows 非法文件名字符 `/ \ : * ? " < > |`、控制字符、结尾的点与空格替换为下划线。
- [ ] 下载使用临时 `<a download>` 保存并释放 blob URL；失败提示「下载失败，请稍后重试」，不改变页面状态。
- [ ] 下载接口只允许 `user.history`；`/images/{id}/content` 与 `/images/{id}/thumbnail` 接受 `user.history` 或 `user.generate`，且只允许读取本人图片。
- [ ] 示例图、失败图、取消半成品、`superseded` 旧图不提供下载入口；直接调用下载接口返回 409 `30005`。
- [ ] 图片不存在或不属于当前用户返回 404 `30014`；缺少 `user.history` 返回 403 `20005`；登录过期按 01 的规则跳转登录。
- [ ] 本切片不引入归档路径解析；05 完成前，`archived_at` 非空的图片按原路径读取会失败，属于已知限制；归档分支由 05 交付。
