## 1. 文档目的与范围

### 1.1 目的

定义普通用户查看自己已生成图片的只读页面：能看到什么、怎么预览、怎么下载、哪些内容不展示。

### 1.2 本期范围

- 历史作品列表（只读）。
- 按生成批次查看一组图。
- 大图预览。
- 单张下载。
- 整组 ZIP 下载。
- 分页。
- 归档数据的展示与下载。

### 1.3 不做

- 删除、编辑、重命名历史作品。
- 收藏、分组、标签。
- 关键词搜索、时间/类型筛选。
- 分享链接、公开访问。
- 查看提示词与完整生成参数（仅后台可看）。

### 2.1 列表形态

- 以**生成批次**为卡片单位，一个 `full` 批次一张卡片。
- 卡片展示：
  - 第 1 张成功图的缩略图作为封面。
  - 商品名称。
  - 图片构成（1 张主图 + 5 张详情图）。
  - 成功张数（如「6 张」「5/6 张」）。
  - 生成时间（本地时区，精确到分钟）。
- 卡片按生成时间倒序排列。
- 每页 20 条，分页器固定在列表下方。

### 2.2 空状态

- 无历史作品时展示插画与文案「还没有作品，去创作台生成第一组图吧」。
- 提供「去创作」按钮，跳转 `/workspace`。

### 2.3 加载与错误

- 首次加载显示骨架屏。
- 加载失败显示「加载失败，点击重试」。
- 归档数据加载较慢时，卡片封面显示占位图与「加载中」。

## 3. 列表数据规则

### 3.1 展示范围

只展示满足以下条件的图片：

1. 属于当前用户。
2. 属于 `full` 批次。
3. 批次状态为 `completed` 或 `partially_failed`。
4. 图片 `image_type=final`。
5. 图片 `status=success`。
6. `is_history_visible=true`。

以下内容**不展示**：

- `sample` 示例批次的示例图。
- 生成失败的图片。
- 取消任务的半成品。
- 被重生成替代的旧图（`superseded`）。
- 其他用户的数据。

### 3.2 部分失败

- `partially_failed` 批次仍展示成功的图片。
- 卡片上显示「成功 5 / 共 6」。
- 失败张不在列表中展示，也不提供补生成入口；用户需回原会话重试。

### 3.3 归档数据

- 满 5 年的图片原件转入 `archive/`，数据库记录保留。
- 列表仍展示封面缩略图（缩略图保留在热存储）。
- 点开大图或下载时，后端从`archive/` 归档前缀读取，可能比热数据慢。
- 归档不影响可见性与下载权限。

## 4. 批次详情

### 4.1 打开方式

- 点击卡片进入批次详情，或在右侧抽屉展示。
- 详情展示该批次全部成功图片，按序号排列。
- 顶部显示：商品名称、图片构成、尺寸、风格、生成时间、成功张数。

### 4.2 图片网格

- 1 张主图 + 5 张详情图，共 6 张，按 `index` 升序。
- 每张显示缩略图与序号。
- 点击缩略图打开大图预览。

### 4.3 大图预览

- 弹层展示原图，支持适应屏幕、100% 查看、上一张/下一张。
- 显示序号与尺寸。
- 提供「下载这张」按钮。
- 关闭后回到网格。

## 5. 下载

### 5.1 单张下载

- 格式：PNG。
- 文件名：`{商品名称}_{主图|详情图}_{序号}_{yyyyMMddHHmmss}.png`。
- 商品名称中的非法文件名字符替换为下划线。
- 下载失败提示「下载失败，请稍后重试」。

### 5.2 整组下载

- 仅批次详情内提供「下载整组」。
- ZIP 内容：
  - 全部成功图片。
  - `manifest.csv`：序号、文件名、状态、尺寸、生成时间。
- ZIP 文件名：`{商品名称}_全套_{yyyyMMddHHmmss}.zip`。
- 部分失败时，ZIP 只包含成功图片，manifest 中列出缺失张。
- ZIP 生成时间较长时显示进度或 loading，不阻塞页面其他操作。

### 5.3 归档图片下载

- 下载请求由后端从`archive/` 归档前缀读取并返回文件流。
- 若归档文件暂时不可用，提示「文件归档中，请稍后重试」，并记录错误。

## 6. 权限与数据边界

| 项目 | 规则 |
| --- | --- |
| 访问角色 | 拥有普通用户角色的账号 |
| 数据范围 | 仅本人 |
| 只读 | 不能删除、编辑、重命名 |
| 下载 | 单张与整组均可 |
| 查看参数 | 不展示提示词与完整参数 |
| 跨用户 | 禁止；后端按 `user_id` 过滤 |

- 管理员/超管不通过该页面查看用户作品，统一走管理后台「内容追溯」。
- 未登录访问 `/history` 跳转登录页。
- 越权访问他人批次返回 403。

| `/api/v1/history` | GET | 分页获取当前用户的历史批次 |

## 9. 验收标准

1. 历史作品只展示当前用户 `full` 批次中的最终成功图。
2. 示例图、失败图、取消半成品、被替代旧图均不展示。
3. 列表按生成时间倒序，每页 20 条，分页可用。
4. 卡片展示封面、商品名称、图片构成、成功张数、生成时间。
5. 点击卡片可查看该批次全部成功图，按序号排列。
6. 大图预览支持上一张/下一张与单张下载。
7. 整组下载生成 ZIP，包含成功图片与 `manifest.csv`。
8. 部分失败批次显示成功张数与总数，ZIP 只含成功图片。
9. 归档数据仍可查看与下载，读取慢时有 loading 提示。
10. 页面不提供删除、编辑、搜索、收藏入口。
11. 未登录跳转登录；越权返回 403。
