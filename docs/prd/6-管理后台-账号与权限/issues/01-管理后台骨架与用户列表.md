# 01: 管理后台骨架、权限点种子与用户列表

**What to build:** 管理员或超管登录后进入 `/admin/accounts`，看到管理后台框架与「账号与权限」下两个 Tab（用户管理 / 角色管理），默认打开用户管理；列表展示用户名、显示名、角色标签、状态、累计统计、创建时间与最后登录，支持关键词、角色、状态、创建时间筛选与分页，空状态与加载失败可重试。普通用户访问管理后台跳 `/403`，无权限接口返回 403。

**Blocked by:** 1 号 demo 的 01~03（工程骨架、登录闭环、登录态与路由守卫）

**Status:** ready-for-agent

- [ ] 管理后台路由 `/admin`、`/admin/accounts` 可访问；「账号与权限」菜单对 `admin` 与 `super_admin` 可见，普通用户不可见且直接访问跳 `/403`。
- [ ] 种子脚本幂等补种 23 个权限点（`user.*` 4 个、`admin.*` 19 个），字段包含 `code`、`name`、`type`（menu/action）、`group_name`（用户端/管理后台）、`is_super_only`；重复执行不覆盖已有数据。
- [ ] 种子脚本为 `user` 角色授予 4 个用户端权限点，为 `admin` 角色授予 13 个默认管理端权限点；`super_admin` 不写入 `role_permissions`，按角色即时授予全部权限点。
- [ ] 新增超管演示账号 `demo_super`，密码 `Demo1234`，bcrypt cost=12；重复执行种子不重置已有密码。
- [ ] 后端权限中间件在每次请求读取当前用户角色与权限（直查 PostgreSQL，不接 Redis）：`super_admin` 直接拥有全部权限点，其余角色取 `role_permissions` 并集；缺失权限返回 403 `20005`。
- [ ] 用户列表返回用户名、显示名、角色（1~2 个，含 `code` 与中文名）、状态、累计生成图片数、累计会话数、累计 Token、创建时间、最后登录；内容表未建时统计返回 `0`，并返回 `stats_available=false`。
- [ ] 支持 `keyword`（用户名或显示名模糊）、`role`、`status`（`active` / `disabled` / `deleted` / `all`，默认 `all`）、`created_from`、`created_to`、`page`、`page_size`（20/50/100，默认 20）。
- [ ] 默认按 `created_at DESC, id DESC` 排序；筛选条件变化后前端回到第 1 页。
- [ ] 列表页展示空状态「暂无用户，点击新建账号」与加载失败「加载失败，点击重试」。
- [ ] 管理员看不到超管账号的查看/编辑/重置密码/禁用/删除按钮，或按钮置灰并提示「无权操作超管账号」。
- [ ] 接口与页面各有可执行的冒烟测试，关键步骤输出中文日志。
