# 04: 禁用/启用、软删除/恢复与旧 Token 失效

**What to build:** 管理员或超管可以禁用、启用、软删除、恢复账号；禁用或删除后账号立即不能登录，已签发的 token 立即失效，历史会话、生图记录与图片全部保留；已删除账号可通过「已删除」筛选查看并恢复；系统始终保留至少一个可用超管。

**Blocked by:** 03（编辑账号与角色边界）

**Status:** ready-for-agent

- [ ] 禁用：状态由 `active` 变为 `disabled`，`token_version` 递增；该账号后续请求返回 403 `20004`；写入 `account.disable`。
- [ ] 启用：状态由 `disabled` 变为 `active`；写入 `account.enable`；已删除账号不能直接启用，返回 409 `30018`。
- [ ] 软删除：状态变为 `deleted`，写入 `deleted_at`，`token_version` 递增；用户名继续被占用，不能被新账号复用；写入 `account.delete`。
- [ ] 恢复：状态由 `deleted` 变为 `active`，清空 `deleted_at`，`token_version` 递增；写入 `account.restore`；恢复后历史数据自动关联。
- [ ] 删除与恢复不删除任何会话、消息、生图记录、图片或文件。
- [ ] 管理员不能禁用/删除超管账号，返回 403 `20006`。
- [ ] 管理员不能禁用/删除自己，返回 403 `20007`；超管不能禁用/删除自己，返回 403 `20007`。
- [ ] 不能禁用/删除最后一个可用超管，返回 409 `30011`。
- [ ] 对已禁用账号再次禁用、对已启用账号再次启用返回成功且不重复写日志；对已删除账号执行禁用/删除、对未删除账号执行恢复返回 409 `30018`。
- [ ] 删除与恢复在前端二次确认；确认文案分别说明「账号将无法登录，历史数据保留」「账号将恢复为启用」。
- [ ] 操作成功后列表与详情刷新，状态标签与按钮随状态切换；失败时 Toast 显示后端 `message`。
- [ ] 接口与页面各有可执行的冒烟测试，关键步骤输出中文日志。
