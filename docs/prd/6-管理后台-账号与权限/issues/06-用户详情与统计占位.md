# 06: 用户详情与统计占位

**What to build:** 管理员或超管从用户列表点击「查看详情」进入用户详情，看到基本信息、统计数据与操作入口；内容入口按钮在本 demo 中为禁用占位。管理员不能查看超管详情。

**Blocked by:** 03（编辑账号与角色边界）

**Status:** ready-for-agent

- [ ] 基本信息展示用户名、显示名、角色、状态、创建时间、最后登录、最后修改时间；从未登录时最后登录显示「—」。
- [ ] 统计区展示累计生成图片数、累计会话数、累计 Token、失败任务数；内容模块未接入时统一为 `0`，并展示提示「统计将在生图模块接入后显示」。
- [ ] 接口返回 `stats_available=false`，前端据此显示占位提示；字段结构保留，后续替换为真实聚合时不改接口。
- [ ] 操作区提供编辑、重置密码、禁用/启用、删除/恢复入口；按钮可用性按账号边界与当前操作者身份计算，后端仍为最终判定。
- [ ] 「查看会话」「查看生图记录」按钮渲染为禁用状态，提示「内容追溯将在 7 号 PRD 实现后开放」，不发起跳转。
- [ ] 管理员查看超管详情返回 403 `20006`；账号不存在返回 404 `30017`。
- [ ] 页面不展示密码、密码哈希或用户上传图原文件。
- [ ] 刷新详情页后数据保持一致；加载失败显示「加载失败，点击重试」。
- [ ] 接口与页面各有可执行的冒烟测试，关键步骤输出中文日志。
