# 08: 操作日志查询

**What to build:** 超管在「操作日志」菜单按时间范围、操作人、动作、结果筛选并分页查看日志，点击某行打开详情抽屉查看 JSON 详情；日志覆盖登录与账号/权限变更，不可编辑、不可删除。

**Blocked by:** 02（新建账号与角色组合校验）

**Status:** ready-for-agent

- [ ] 「操作日志」菜单仅超管可见；管理员或普通用户访问页面跳 `/403`，接口返回 403 `20005`。
- [ ] 列表展示时间（精确到秒、本地时区）、操作人用户名与用户 ID、动作、对象类型、对象标识、结果、IP；默认按时间倒序，每页 20 条。
- [ ] 支持筛选：时间范围、操作人关键词、动作码、结果（`success` / `failed` / `all`）；筛选变化后回到第 1 页。
- [ ] 列表分页返回 `items`、`total`、`page`、`page_size`。
- [ ] 点击行打开详情抽屉，展示浏览器标识 `user_agent` 与 `detail` JSON（格式化展示）。
- [ ] 登录成功/失败（复用 1 号 demo）与账号创建、编辑、重置密码、禁用、启用、删除、恢复、角色权限变更均可查到，动作码与接口文档一致。
- [ ] 密码、密码哈希、API Key 等敏感值不出现在 `detail` 中。
- [ ] 日志详情不存在返回 404 `30019`。
- [ ] 页面不提供编辑、删除日志的入口；后端不提供对应接口。
- [ ] 日志列表加载失败显示「加载失败，点击重试」；空结果显示「暂无操作日志」。
- [ ] 接口与页面各有可执行的冒烟测试，关键步骤输出中文日志。
