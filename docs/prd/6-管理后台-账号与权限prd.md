## 1. 文档目的与范围

### 1.1 目的

定义管理后台的账号体系与权限控制：用户管理、角色管理、权限点配置、账号边界，以及操作日志（本文件同时承担审计模块的 PRD）。

### 1.2 本期范围

- 用户列表、筛选、分页。
- 新建账号、编辑账号、重置密码、禁用/启用、软删除/恢复。
- 用户详情（账号信息与统计，内容追溯跳转见 `7-管理后台-用户与生图记录prd.md`）。
- 三个固定角色的定义与组合规则。
- 权限点目录与角色权限配置（仅超管可编辑）。
- 账号操作边界与防越权规则。
- 操作日志查询（仅超管）。

### 1.3 不做

- 用户自助注册。
- 自定义新建角色。
- 邮箱/短信邀请与验证。
- 密码找回流程（由管理员重置）。
- 用户组、部门、组织架构。
- 登录失败锁定与验证码。

## 2. 菜单结构

「账号与权限」菜单包含两个 Tab：

| Tab | 可见角色 | 说明 |
| --- | --- | --- |
| 用户管理 | 管理员、超管 | 账号增删改查、重置密码、禁用/启用 |
| 角色管理 | 仅超管 | 查看三个角色、编辑管理员/普通用户的权限点 |

「操作日志」为独立菜单，仅超管可见；数据与账号/权限变更共用同一审计表。

## 3. 用户管理

### 3.1 列表字段

| 字段 | 说明 |
| --- | --- |
| 用户名 | 唯一，不可修改 |
| 显示名 | 可修改 |
| 角色 | 显示一个或两个角色标签 |
| 状态 | 启用 / 禁用 / 已删除 |
| 累计生成图片数 | 该用户所有 `success` 的正式图数量 |
| 累计会话数 | 该用户未删除与已隐藏的会话总数 |
| 累计 Token | 该用户所有 Agent 调用的输入 + 输出 Token |
| 创建时间 | 本地时区 |
| 最后登录 | 本地时区；从未登录显示「—」 |

### 3.2 筛选与排序

| 筛选项 | 类型 | 说明 |
| --- | --- | --- |
| 关键词 | 输入框 | 匹配用户名或显示名，模糊搜索 |
| 角色 | 下拉 | 普通用户 / 管理员 / 超管 |
| 状态 | 下拉 | 启用 / 禁用 / 已删除 / 全部 |
| 创建时间 | 日期范围 | 起止日期 |

- 默认按创建时间倒序。
- 分页每页 20 条，可切换 20/50/100。
- 筛选条件变化后回到第 1 页。

### 3.3 行内操作

| 操作 | 管理员可用 | 超管可用 | 说明 |
| --- | --- | --- | --- |
| 查看详情 | ✓（非超管账号） | ✓ | 打开用户详情 |
| 编辑 | ✓（非超管账号） | ✓ | 改显示名、角色、状态 |
| 重置密码 | ✓（非超管账号） | ✓ | 设置新密码 |
| 禁用/启用 | ✓（非超管账号） | ✓ | 切换状态 |
| 删除 | ✓（非超管账号） | ✓ | 软删除 |
| 恢复 | ✓（仅已删除的非超管账号） | ✓ | 恢复为启用 |

- 管理员看不到超管账号的操作按钮，或按钮置灰并提示「无权操作超管账号」。
- 管理员不能编辑自己的角色；自己的「编辑」按钮中角色字段只读。
- 超管不能删除或禁用自己。

### 3.4 空状态与错误

| 场景 | 展示 |
| --- | --- |
| 无用户 | 空状态「暂无用户，点击新建账号」 |
| 加载失败 | 「加载失败，点击重试」 |
| 无权限 | 跳转 `/403` |
| 操作失败 | Toast 显示后端错误信息 |

## 4. 新建账号

### 4.1 字段

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 用户名 | 是 | 4~20 位字母、数字、下划线；全局唯一（含已删除账号）；创建后不可修改 |
| 显示名 | 是 | 1~30 个字符；去除首尾空格 |
| 初始密码 | 是 | 6~32 位；不做复杂度要求；创建后不可查看 |
| 角色 | 是 | 1~2 个角色；按组合规则校验 |
| 状态 | 是 | 启用 / 禁用；默认启用 |

### 4.2 角色可选项

- 管理员创建账号时：只能分配「普通用户」「管理员」及其允许的组合；不能分配超管。
- 超管创建账号时：可分配全部允许的组合。
- 不允许选择「超管 + 管理员」组合。
- 不允许选择超过 2 个角色。

### 4.3 创建流程

1. 管理员填写字段。
2. 前端校验格式与角色组合。
3. 提交 `POST /api/v1/admin/users`。
4. 后端再次校验用户名唯一性、角色组合、操作者权限。
5. 密码使用 bcrypt 哈希后存储。
6. 写入操作日志：动作「创建账号」，对象为用户名。
7. 返回账号信息，弹出成功提示；不回显密码。

### 4.4 初始密码交付

- 系统不发送邮件或短信。
- 管理员线下把用户名与初始密码告知用户。
- 用户登录后可在个人中心自行修改密码。

## 5. 编辑账号

### 5.1 可编辑字段

| 字段 | 可编辑 | 说明 |
| --- | --- | --- |
| 用户名 | 否 | 创建后不可改 |
| 显示名 | 是 | 1~30 字符 |
| 角色 | 是 | 按权限与组合规则校验 |
| 状态 | 是 | 启用 / 禁用 |
| 密码 | 否 | 通过「重置密码」单独操作 |

### 5.2 规则

1. 管理员不能编辑超管账号。
2. 管理员不能修改自己的角色。
3. 管理员不能把任何账号的角色改为超管。
4. 超管不能移除自己的超管角色。
5. 修改角色后，写入操作日志，记录修改前后角色。
6. 角色变更在用户下一次请求时生效；前端菜单在刷新或重新登录后更新。
7. 不能通过编辑把最后一个可用超管降级。

## 6. 重置密码

### 6.1 操作

1. 点击「重置密码」。
2. 弹窗输入新密码与确认密码。
3. 校验：6~32 位；两次一致；不能为空。
4. 提交 `POST /api/v1/admin/users/{id}/reset-password`。
5. 成功后提示「密码已重置，请线下告知用户」。
6. 写入操作日志，不记录密码内容。

### 6.2 生效规则

- 重置后，用户旧 token 立即失效（通过 `users.token_version` 递增实现）。
- 用户需使用新密码重新登录。
- 不强制用户下次登录修改密码。

### 6.3 权限

- 管理员可重置普通用户与管理员（非超管）的密码。
- 管理员不能重置超管密码。
- 超管可重置除自己以外任何账号的密码；自己的密码通过个人中心修改。

## 7. 禁用 / 启用

### 7.1 禁用

- 将账号状态置为 `disabled`。
- 该账号立即不能登录，已签发 token 失效（`token_version` 递增 + 状态校验）。
- 历史会话、生图记录、图片全部保留。
- 写入操作日志。

### 7.2 启用

- 将 `disabled` 账号恢复为 `active`。
- 用户可重新登录。
- 写入操作日志。

### 7.3 边界

1. 管理员不能禁用超管账号。
2. 管理员不能禁用自己。
3. 超管不能禁用自己。
4. 不能禁用最后一个可用的超管账号。
5. 已删除账号需先恢复，不能直接启用。

---

## 8. 软删除 / 恢复

### 8.1 删除

- 将账号状态置为 `deleted`，记录 `deleted_at`。
- 账号不能登录，已签发 token 失效。
- 用户名继续被占用，不能被新账号复用。
- 会话、消息、生图记录、图片全部保留。
- 写入操作日志。

### 8.2 恢复

- 将 `deleted` 账号恢复为 `active`。
- 恢复后用户名不变，历史数据自动关联。
- 写入操作日志。

### 8.3 边界

1. 管理员不能删除超管账号。
2. 管理员不能删除自己。
3. 超管不能删除自己。
4. 不能删除最后一个可用超管账号。
5. 删除与恢复均需二次确认。

## 9. 用户详情

### 9.1 展示内容

| 区块 | 内容 |
| --- | --- |
| 基本信息 | 用户名、显示名、角色、状态、创建时间、最后登录、最后修改时间 |
| 统计数据 | 累计生成图片数、累计会话数、累计 Token、失败任务数 |
| 操作 | 编辑、重置密码、禁用/启用、删除/恢复 |
| 内容入口 | 「查看会话」「查看生图记录」按钮，跳转内容追溯并按该用户筛选 |

### 9.2 不做

- 不展示密码或密码哈希。
- 不展示用户上传图的原始文件（在会话/生图详情中查看）。
- 不允许在详情页直接替用户生成图片。

### 9.3 权限

- 管理员可查看非超管账号详情。
- 超管可查看所有账号详情。

## 10. 角色模型

### 10.1 固定角色

| 角色 | `code` | 说明 |
| --- | --- | --- |
| 普通用户 | `user` | 创作台、历史作品、个人中心 |
| 管理员 | `admin` | 用户管理、素材模板、系统提示词、内容追溯、Token 统计 |
| 超管 | `super_admin` | 拥有管理员全部权限，另加模型配置、角色权限编辑、操作日志、数据导出 |

### 10.2 组合规则

允许：

1. 仅普通用户
2. 仅管理员
3. 仅超管
4. 管理员 + 普通用户
5. 超管 + 普通用户

禁止：

- 超管 + 管理员
- 超管 + 管理员 + 普通用户
- 任何超过 2 个角色的组合
- 0 个角色

### 10.3 超管权限包含管理员

- 超管不依赖 `role_permissions` 判断，系统始终赋予超管全部权限。
- 管理员被授予的权限，超管天然拥有。
- 即使超管在角色管理页移除了管理员的某项权限，超管仍保有该权限。

### 10.4 只有管理员/超管角色时

- 不能进入创作台。
- 若需要使用创作能力，必须同时拥有普通用户角色。

### 11.1 权限点清单

| 权限码 | 名称 | 类型 | 默认角色 | 超管专属 |
| --- | --- | --- | --- | --- |
| `user.workspace` | 创作台 | 菜单 | 普通用户 | 否 |
| `user.generate` | 发起生成 | 操作 | 普通用户 | 否 |
| `user.history` | 历史作品 | 菜单 | 普通用户 | 否 |
| `user.profile` | 个人中心 | 菜单 | 普通用户 | 否 |
| `admin.dashboard.view` | 概览 | 菜单 | 管理员 | 否 |
| `admin.accounts.view` | 用户管理 | 菜单 | 管理员 | 否 |
| `admin.accounts.create` | 新建账号 | 操作 | 管理员 | 否 |
| `admin.accounts.edit` | 编辑账号 | 操作 | 管理员 | 否 |
| `admin.accounts.reset_password` | 重置密码 | 操作 | 管理员 | 否 |
| `admin.accounts.disable` | 禁用/启用 | 操作 | 管理员 | 否 |
| `admin.accounts.delete` | 删除/恢复 | 操作 | 管理员 | 否 |
| `admin.roles.view` | 角色管理 | 菜单 | 超管 | 是 |
| `admin.roles.edit` | 编辑权限点 | 操作 | 超管 | 是 |
| `admin.content.view` | 内容追溯 | 菜单 | 管理员 | 否 |
| `admin.assets.view` | 素材与模板 | 菜单 | 管理员 | 否 |
| `admin.assets.edit` | 编辑素材/模板/尺寸 | 操作 | 管理员 | 否 |
| `admin.prompts.view` | 系统提示词 | 菜单 | 管理员 | 否 |
| `admin.prompts.edit` | 编辑系统提示词 | 操作 | 管理员 | 否 |
| `admin.model.view` | 模型配置 | 菜单 | 超管 | 是 |
| `admin.model.edit` | 编辑模型配置 | 操作 | 超管 | 是 |
| `admin.tokens.view` | Token 统计 | 菜单 | 管理员 | 否 |
| `admin.audit.view` | 操作日志 | 菜单 | 超管 | 是 |
| `admin.export` | 数据导出 | 操作 | 超管 | 是 |

### 11.2 权限点规则

1. 权限点分「菜单」与「操作」两类。
2. **超管专属权限点不能授予管理员或普通用户**，后端必须拒绝。
3. 普通用户角色至少保留 `user.workspace`；管理员角色至少保留 `admin.dashboard.view`；否则不允许保存。
4. 超管角色权限固定为全部，不可编辑。
5. 权限校验以后端为准；前端菜单隐藏只是体验优化。
6. 权限变更写入操作日志。

## 12. 角色管理页（仅超管）

### 12.1 页面结构

| 区块 | 内容 |
| --- | --- |
| 角色列表 | 普通用户、管理员、超管三张角色卡 |
| 权限树 | 按「用户端 / 管理后台」分组，展示菜单与操作权限点 |
| 操作 | 勾选/取消（普通用户、管理员）；超管只读 |
| 保存 | 保存后立即生效 |

### 12.2 规则

1. 超管角色卡显示全部权限，全部只读，提示「超管拥有全部权限」。
2. 普通用户与管理员角色卡可勾选非超管专属权限点。
3. 超管专属权限点在管理员/普通用户视图中置灰或隐藏，并提示「仅超管可用」。
4. 保存前校验第 11.2 节的最低权限要求。
5. 不支持新建角色、删除角色、重命名角色。
6. 保存成功后，刷新当前权限缓存；其他在线用户在下一次请求或刷新页面后生效。

### 12.3 冲突处理

- 若保存时发现权限点已被其他超管修改，返回冲突错误，要求刷新后重试。
- 不做并发合并，避免权限状态不确定。

## 13. 账号操作边界汇总

| 操作者 | 目标 | 允许 |
| --- | --- | --- |
| 管理员 | 普通用户 | 查看、编辑、重置密码、禁用/启用、删除/恢复 |
| 管理员 | 其他管理员 | 查看、编辑、重置密码、禁用/启用、删除/恢复 |
| 管理员 | 超管 | 全部禁止 |
| 管理员 | 自己 | 查看、改显示名、重置密码；**不能改角色、不能禁用、不能删除** |
| 超管 | 任意非自己账号 | 查看、编辑、重置密码、禁用/启用、删除/恢复（含其他超管，需保留至少一个超管） |
| 超管 | 自己 | 查看、改显示名、改密码；**不能改超管角色、不能禁用、不能删除** |

## 14. 操作日志

### 14.1 记录范围

至少记录：

- 登录成功/失败。
- 创建、编辑、禁用/启用、删除/恢复账号。
- 重置密码。
- 角色权限点变更。
- 模板/素材/尺寸变更。
- 模型配置变更。
- 系统提示词变更。
- 数据导出。
- 生成任务取消（可选）。

### 14.2 字段

| 字段 | 说明 |
| --- | --- |
| 时间 | 精确到秒，本地时区 |
| 操作人 | 用户名 + 用户 ID |
| 动作 | 如 `account.create`、`role.update` |
| 对象类型 | 账号 / 角色 / 模板 / 素材 / 配置 / 提示词 / 导出 |
| 对象标识 | 如用户名、模板 ID |
| 结果 | 成功 / 失败 |
| IP | 操作来源 IP |
| User-Agent | 浏览器标识 |
| 详情 | JSON，记录变更前后摘要；不记录密码、API Key 等敏感值 |

### 14.3 查询页

- 仅超管可见。
- 筛选：时间范围、操作人关键词、动作、结果。
- 列表按时间倒序，每页 20 条。
- 点击行打开详情抽屉，展示 JSON 详情。
- 不支持编辑、删除日志。
- 日志随业务数据保留 5 年。

## 16. 验收标准

1. 用户列表支持关键词、角色、状态、创建时间筛选与分页。
2. 新建账号可设置用户名、显示名、初始密码、角色、状态；用户名唯一且创建后不可改。
3. 角色组合只允许五种合法组合，超管+管理员被拒绝。
4. 管理员不能查看/操作超管账号，不能改自己的角色。
5. 超管不能删除/禁用自己，系统始终保留至少一个可用超管。
6. 禁用、删除后账号不能登录，旧 token 失效，历史数据保留。
7. 软删除账号可通过「已删除」筛选查看并恢复，用户名不被复用。
8. 重置密码后旧 token 失效，用户需用新密码登录。
9. 角色管理仅超管可见，可编辑普通用户/管理员的权限点，超管权限只读且始终为全部。
10. 超管专属权限点不能被授予管理员/普通用户。
11. 权限校验在后端生效，越权返回 403。
12. 操作日志记录登录、账号、权限、配置、导出等关键动作，仅超管可查。
13. 操作日志不记录密码、API Key 等敏感值。
14. 所有账号与权限变更均可在日志中追溯。
