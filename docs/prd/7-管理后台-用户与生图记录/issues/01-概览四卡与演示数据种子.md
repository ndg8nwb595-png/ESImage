# 01: 概览四卡与演示数据种子

**What to build:** 管理员或超管登录后进入 `/admin/dashboard`，看到管理后台概览页与四张统计卡片（用户总数、今日生成图片数、累计图片数、今日 Token），卡片数据缓存 60 秒；提供「用户管理」「生图记录」「Token 统计」快捷入口，点击「今日生成图片数」「累计图片数」跳转生图记录并带当天日期筛选。同时提供一份幂等的管理端演示数据种子，覆盖多用户、会话、批次、图片、Agent 调用、归档图、失败与替代图，供 02~06 切片复用。

**Blocked by:** 6 号 demo 01（管理后台骨架、权限点与用户列表）、4 号 demo 01（生成数据模型与 Agent 运行时）

**Status:** ready-for-agent

- [ ] `/admin/dashboard` 路由与「概览」菜单可访问；拥有 `admin.dashboard.view` 的管理员与超管可见，普通用户不可见且直接访问跳 `/403`。
- [ ] 四张卡片口径正确：用户总数 = `users.status != deleted` 的账号数；今日生成图片数 = 当天创建、`image_type=final`、`status=success` 的图片数；累计图片数 = 全部 `image_type=final`、`status=success` 的图片数（含被重生成替代的旧图）；今日 Token = 当天 `agent_runs` 输入 + 输出 Token 总和。
- [ ] 「当天」按 Asia/Shanghai 计算；数字超过 10000 使用千分位；无数据显示 `0`。
- [ ] 卡片数据缓存 60 秒，TTL 可由 `DASHBOARD_CACHE_TTL_SECONDS` 覆盖；60 秒内重复请求返回同一快照，过期后重新聚合；缓存为进程内单实例实现，提供测试可调用的清缓存入口。
- [ ] 加载失败显示「加载失败，点击重试」；重试后恢复；不因单卡失败导致整页空白。
- [ ] 快捷入口：「用户管理」跳转账号与权限页；「生图记录」跳转内容追溯页；「Token 统计」切换到概览的 Token Tab。
- [ ] 「今日生成图片数」与「累计图片数」均可点击，跳转 `/admin/content?start_date={今天}&end_date={今天}`；日期按 Asia/Shanghai 生成。
- [ ] 种子脚本幂等：创建 `demo_user2`（普通用户，密码 `Demo1234`），补齐 `demo_user`、`demo_super` 的内容数据；重复执行不重复创建、不重置已有密码与权限。
- [ ] 种子覆盖 `demo_user` 的 `sample_ready` 示例批次、`completed` 全套批次、`partially_failed` 全套批次、`failed` 示例批次、`cancelled` 全套批次、归档 `completed` 全套批次；`demo_user2` 的 `partially_failed` 批次；`demo_super` 的 `completed` 批次，用于验证管理员过滤超管内容。
- [ ] 种子图片覆盖 `main`/`detail`、`success`/`failed`/`cancelled`/`superseded`、`image_type=sample/final`，并包含 1 张 `archived_at` 非空的成功正式图；缩略图与归档文件写入本地存储，网格可加载。
- [ ] 种子 `agent_runs` 覆盖 8 个 Agent、跨 7 个自然日、2 个模型名，包含 `success`、`failed`（有 Token 与 0 Token 各一条）、`skipped`（0 Token），供 Token 统计验证。
- [ ] 种子不调用豆包、不需要 `DOUBAO_API_KEY`；不写入导出任务或 `export.*` 审计日志；不修改 4 号 demo 真实生成数据。
- [ ] 接口与页面各有可执行冒烟测试，关键步骤输出中文日志（如「[概览] 缓存命中」「[种子] 第 2 次执行未新增数据」）。
- [ ] 本切片不实现 Token Tab 的筛选与明细、生图记录页面、单图详情、用户详情统计；只交付概览页、概览接口与可复用的种子模块。
