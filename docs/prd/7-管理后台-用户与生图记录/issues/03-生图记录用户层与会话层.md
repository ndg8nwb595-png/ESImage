# 03: 生图记录：用户层与会话层

**What to build:** 管理员或超管进入 `/admin/content` 生图记录页，看到「用户列表 / 会话与批次树 / 图片网格」三栏骨架。左侧展示有生成记录的用户，支持用户名/显示名关键词搜索，按最后生成时间倒序分页；点击用户后中间栏加载该用户的会话列表，包含活跃与隐藏会话，按最近消息时间倒序分页，默认展开最近一个会话。管理员看不到超管账号的用户、会话与内容。

**Blocked by:** 01（概览四卡与演示数据种子）

**Status:** ready-for-agent

- [ ] `/admin/content` 路由与「内容追溯 → 生图记录」菜单可访问；拥有 `admin.content.view` 的管理员与超管可见，普通用户不可见且直接访问跳 `/403`。
- [ ] 页面呈现三栏骨架：左侧用户列表、中间会话/批次树、右侧图片网格占位；浏览器宽度不足时保持可用，不横向溢出页面主体。
- [ ] 左侧用户列表支持关键词搜索（用户名/显示名模糊）；只展示至少存在 1 个 `generation_batches` 记录的用户；按 `last_generated_at DESC` 排序，分页默认 20 条。
- [ ] 用户列表项展示用户名、显示名、账号状态、最后生成时间；已删除/禁用用户仍可出现并显示状态；关键词无结果时展示「没有符合条件的记录」。
- [ ] 选择用户后加载会话列表；包含 `active` 与 `hidden` 会话；展示会话标题、状态、最后消息时间、批次数量、最近批次时间；按 `COALESCE(last_message_at, created_at) DESC` 排序，分页默认 20 条。
- [ ] 默认展开最近一个会话；切换用户后重置到该用户最近会话；会话无批次时展示「该会话暂无生成批次」。
- [ ] 管理员（`admin`）的左侧用户列表过滤掉拥有 `super_admin` 角色的用户；用超管用户 ID 直接请求会话列表返回 403 `20006`；超管（`super_admin`）可看到全部。
- [ ] 普通用户调用内容追溯接口返回 403 `20005`；未登录返回 401；账号禁用/删除返回 403 `20004`。
- [ ] 用户不存在返回 404 `30017`；会话不存在返回 404 `30013`；会话所属用户为超管且当前为管理员时返回 403 `20006`。
- [ ] 加载失败显示「加载失败，点击重试」；切换筛选后回到第 1 页；接口响应字段不省略空值。
- [ ] 种子数据保证 `demo_user`、`demo_user2`、`demo_super` 均有内容，可演示多用户、隐藏会话与超管过滤。
- [ ] 接口与页面各有可执行冒烟测试，关键步骤输出中文日志（如「[生图记录] 用户列表按最后生成时间倒序」「[生图记录] 管理员过滤超管用户」）。
- [ ] 本切片不实现批次展开、图片网格、单图详情；中间栏批次节点与右侧网格只做占位。
