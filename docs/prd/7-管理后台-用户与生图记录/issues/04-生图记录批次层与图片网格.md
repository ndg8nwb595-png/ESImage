# 04: 生图记录：批次层与图片网格

**What to build:** 在生图记录页展开会话，中间栏显示该会话的生成批次；支持按商品名称、批次类型、批次状态、批次创建时间筛选，展示批次类型、状态、商品名称、图片构成、总张数、已完成张数与创建时间。选中批次后右侧图片网格展示缩略图、序号、图片角色与状态角标，支持按图片角色、图片状态筛选与分页；默认每个序号只展示最新一次尝试，可切换查看被替代的旧图。

**Blocked by:** 03（生图记录：用户层与会话层）

**Status:** ready-for-agent

- [ ] 展开会话后显示批次列表；批次项展示批次类型（示例/全套）、状态、商品名称、图片构成（主图数 + 详情图数）、`completed_count/total_count`、创建时间；默认按创建时间倒序，分页 20 条。
- [ ] 图片构成按计划口径：`sample` 批次为 1 主图 + 0 详情图；`full` 批次为 1 主图 + (`total_count - 1`) 详情图；不因实际失败/替代张数改变展示口径。
- [ ] 批次筛选：商品名称（批次快照模糊匹配）、批次类型（`sample`/`full`/`all`）、批次状态（8 种 + `all`）、批次创建时间范围（`start_date`/`end_date`，Asia/Shanghai，含边界）；条件可组合。
- [ ] 筛选无结果时展示「没有符合条件的记录」；切换筛选后回到第 1 页；加载失败可重试。
- [ ] 选中批次后加载图片网格；图片项展示缩略图、序号、图片角色（主图/详情图）、状态角标、尝试次数；默认按序号升序、尝试次数倒序。
- [ ] 图片网格筛选：图片角色（`main`/`detail`/`all`）、图片状态（`pending`/`generating`/`success`/`failed`/`cancelled`/`superseded`/`all`）；分页默认 20 条。
- [ ] 默认每个 `index_no` 只返回最新一次尝试（`include_superseded=false`）；`include_superseded=true` 返回全部尝试；`status=superseded` 时自动包含旧图。旧图在网格中显示「已被替代」角标，不与当前图混淆。
- [ ] 缩略图通过管理端鉴权接口获取；前端带 token 取 Blob 后展示，不把 token 拼进图片 URL；缩略图缺失或加载失败显示占位图，不阻塞其他图片渲染。
- [ ] 管理员访问超管会话的批次或图片返回 403 `20006`；普通用户返回 403 `20005`；会话不存在返回 404 `30013`，批次不存在返回 404 `30004`。
- [ ] 种子数据覆盖 6 种批次状态与多种图片状态，可演示筛选、空状态、失败与替代图。
- [ ] 接口与页面各有可执行冒烟测试，关键步骤输出中文日志（如「[图片网格] 默认仅展示最新尝试」「[批次筛选] 部分失败批次命中」）。
- [ ] 本切片不实现单图详情抽屉、大图预览与原图下载；点击图片只预留事件，不打开详情。
