# 05: 单图详情与媒体访问

**What to build:** 管理员或超管在图片网格点击任意图片，打开单图详情抽屉，查看大图预览与完整生成信息：图片 ID、所属用户、会话、批次、序号、状态、商品名称、风格、尺寸、图片角色、模板、最终提示词、负面提示词、模型、耗时、Token、错误信息、创建时间、文件路径、是否历史可见。支持缩放预览、下载原图、跳转会话与用户详情；归档图片仍展示元数据，大图与下载从 `archive/` 读取，慢读显示「正在从归档读取…」，不可用提示「文件归档中，请稍后重试」。

**Blocked by:** 04（生图记录：批次层与图片网格）、2/4 号 demo 的存储适配层；5 号 demo 05 的归档读取可复用（非硬阻塞）

**Status:** ready-for-agent

- [ ] 点击图片网格项打开详情抽屉；抽屉展示 PRD §7.1 的全部字段，空值显示 `—` 或 `null` 对应文案，不省略字段。
- [ ] 大图预览支持缩放；预览失败显示占位与重试入口；不因单图失败导致抽屉崩溃。
- [ ] 「下载原图」以附件返回，文件名按 `{商品名称}_{主图|详情图}_{序号}_{yyyyMMddHHmmss}.png` 生成，非法字符替换为下划线，使用 RFC 5987 编码；示例图、正式图、成功旧图有文件时可下载，无文件或失败图返回 404 `30014`。
- [ ] 「跳转会话」指向 `/admin/chat?session_id={session_id}`（8 号 demo 页面，未实现时置灰并提示）；「跳转用户详情」指向 `/admin/accounts/{user_id}`。
- [ ] 不提供删除、重新生成、修改提示词、修改状态入口；详情页只读。
- [ ] 新增管理端媒体接口：大图预览、原图下载；缩略图复用 04 已交付的 `/thumbnail`。均校验 JWT 与 `admin.content.view`，管理员访问超管内容返回 403 `20006`，普通用户返回 403 `20005`。
- [ ] 图片不存在返回 404 `30024`；文件缺失返回 404 `30014`；存储异常返回 500 `50003`；错误响应为统一 JSON 结构，成功响应为二进制流。
- [ ] 归档图片（`archived_at` 非空）：详情元数据正常；缩略图仍从 `thumbnails/` 热存储读取；大图与下载从 `archive/{file_path}` 读取。
- [ ] 归档读取超过 `ARCHIVE_READ_TIMEOUT_SECONDS`（默认 60 秒）、文件缺失或存储异常时，预览与下载返回 404 `30014`，前端提示「文件归档中，请稍后重试」，并保留关闭入口。
- [ ] 前端大图或归档读取超过 300ms 未返回时显示「正在从归档读取…」；返回后正常展示；不把归档慢读误判为失败。
- [ ] 详情抽屉展示 `file_path`（MinIO 对象路径）与 `is_history_visible`；不展示用户密码、API Key、JWT 等敏感信息。
- [ ] 种子数据包含 1 张归档成功图，可演示元数据、缩略图、归档预览/下载与不可用降级。
- [ ] 接口与页面各有可执行冒烟测试，关键步骤输出中文日志（如「[单图详情] 归档读取成功」「[单图下载] 文件名编码正确」）。
