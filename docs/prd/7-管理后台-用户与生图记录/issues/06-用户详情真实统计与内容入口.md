# 06: 用户详情真实统计与内容入口

**What to build:** 在 6 号 demo 的用户列表与用户详情基础上，把累计生成图片数、累计会话数、累计 Token、失败任务数从占位 `0` 替换为真实聚合，并返回 `stats_available=true`；启用用户详情中的「查看会话」「查看生图记录」按钮，分别跳转到聊天记录页与生图记录页，并带上该用户 ID 作为筛选条件。管理员仍不能查看超管账号详情。

**Blocked by:** 6 号 demo 06（用户详情与统计占位）、03（生图记录用户层与会话层）、4 号 demo 01（生成数据模型）

**Status:** ready-for-agent

- [ ] `GET /api/v1/admin/users` 与 `GET /api/v1/admin/users/{id}` 的 `stats` 字段结构保持不变；`stats_available` 返回 `true`，数值为真实聚合。
- [ ] `image_count` = 该用户 `generated_images.image_type=final` 且 `status=success` 的图片数（含被替代的旧成功图）。
- [ ] `session_count` = 该用户全部会话数（`active` + `hidden`）。
- [ ] `token_total` = 该用户 `agent_runs` 输入 + 输出 Token 之和，归属规则与 Token 统计一致；`skipped` 的 0 Token 不影响结果。
- [ ] `failed_task_count` = 该用户 `generation_batches.status IN ('failed','partially_failed')` 的批次数。
- [ ] 列表页统计使用批量聚合查询，避免逐用户 N+1；详情页与列表页同一用户数值一致。
- [ ] 用户详情页启用「查看会话」与「查看生图记录」按钮；「查看生图记录」跳转 `/admin/content?user_id={id}`，内容页选中该用户并加载会话；「查看会话」跳转 `/admin/chat?user_id={id}`，8 号 demo 未实现时按钮置灰并提示。
- [ ] 内容页支持 `user_id` 查询参数：若用户存在且有内容，左侧列表定位并选中该用户；若用户无生成记录，列表展示空状态并提示「该用户暂无生成记录」。
- [ ] 管理员查看超管账号详情返回 403 `20006`；普通用户访问用户列表/详情返回 403 `20005`；用户不存在返回 404 `30017`。
- [ ] 统计值与种子数据一致；与 Token 统计中同一用户、同一时间范围的合计可交叉核对。
- [ ] 接口与页面各有可执行冒烟测试，关键步骤输出中文日志（如「[用户统计] 累计 Token 与明细合计一致」「[内容入口] 按 user_id 定位用户」）。
- [ ] 本切片不实现账号编辑、重置密码、禁用/启用、删除/恢复；不改变 6 号 demo 的账号边界。
