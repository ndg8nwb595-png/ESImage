## 1. 文档目的与范围

### 1.1 目的

定义管理后台的「概览」与「内容追溯 → 生图记录」：管理者能看到多少用户、生成了多少图、每个用户的历史生图记录、每张图的完整生成信息，以及超管的全量数据导出。

### 1.2 本期范围

- 概览首页四张统计卡片。
- Token 统计 Tab（按用户 / Agent / 日期 / 模型）。
- 用户详情中的内容入口（账号信息见 `6-管理后台-账号与权限/6-管理后台-账号与权限prd.md`）。
- 生图记录的三层钻取：用户 → 会话 → 生成批次 → 单张图。
- 单张图的参数、提示词、模型、耗时、Token、状态与图片预览。
- 超管数据导出（图片 ZIP + 元数据 CSV）。
- 相关权限与审计。

### 1.3 不做

- 图表趋势、排行、报表订阅。
- 按金额换算 Token 成本。
- 后台替用户重新生成图片。
- 删除用户生图记录或图片文件。
- 直连数据库执行 SQL。

## 3. 概览首页

### 3.1 统计卡片

| 卡片 | 口径 |
| --- | --- |
| 用户总数 | `users.status != deleted` 的账号数 |
| 今日生成图片数 | 当天创建、`image_type=final`、`status=success` 的图片数 |
| 累计图片数 | 全部 `image_type=final`、`status=success` 的图片数 |
| 今日 Token | 当天 `agent_runs` 的输入 + 输出 Token 总和 |

- 卡片数据实时查询，不做缓存，或缓存不超过 60 秒。
- 数字超过 10000 时使用千分位。
- 点击「今日生成图片数」「累计图片数」跳转到生图记录并带上日期筛选。

### 3.2 快捷入口

- 「用户管理」跳转账号与权限。
- 「生图记录」跳转内容追溯。
- 「Token 统计」切换到概览的 Token Tab。

### 3.3 空状态与错误

- 无数据时卡片显示 0。
- 加载失败显示「加载失败，点击重试」。

## 4. Token 统计

### 4.1 筛选

| 筛选项 | 说明 |
| --- | --- |
| 时间范围 | 起止日期，默认最近 7 天 |
| 用户 | 关键词搜索用户名/显示名，可清空 |
| Agent | 8 个 Agent 下拉，可多选 |
| 模型 | 文本模型名或图像模型名 |

### 4.2 汇总

- 输入 Token 合计。
- 输出 Token 合计。
- 总 Token。
- 调用次数（`agent_runs` 记录数）。

### 4.3 明细表

| 列 | 说明 |
| --- | --- |
| 日期 | 按天聚合 |
| 用户 | 用户名 + 显示名 |
| Agent | Agent 名称 |
| 模型 | 模型名 |
| 调用次数 | 该组合的调用数 |
| 输入 Token | 合计 |
| 输出 Token | 合计 |
| 合计 Token | 输入 + 输出 |

- 按日期倒序、合计 Token 倒序。
- 分页每页 20 条。
- 不提供图表、导出、金额换算。

### 4.4 数据口径

- 只统计 `agent_runs.status=success` 或 `failed` 中有 Token 返回的记录。
- 被跳过（`skipped`）的 Agent 不计 Token。
- 失败但已产生 Token 的调用计入，并在明细中可通过状态列区分（可选列）。
- 时区按 Asia/Shanghai。

## 6. 生图记录：三层钻取

### 6.1 页面布局

```
┌──────────────────────────────────────────────────────────────────┐
│ 内容追溯 / 生图记录                                               │
│ 筛选：用户 [____] 商品名称 [____] 图片角色 ▾ 批次类型 ▾ 状态 ▾   │
│       时间 [起] - [止]                              [查询] [重置] │
├──────────────┬──────────────────┬────────────────────────────────┤
│ 用户列表      │ 会话 / 批次树     │ 图片网格 / 单图详情             │
│ ○ 张三        │ 会话 A           │ ┌────┐ ┌────┐ ┌────┐           │
│ ○ 李四        │  ├ 示例批次 #12  │ │ 图1 │ │ 图2 │ │ 图3 │           │
│ ...          │  └ 全套批次 #13  │ └────┘ └────┘ └────┘           │
└──────────────┴──────────────────┴────────────────────────────────┘
```

### 6.2 第一层：用户

- 左侧用户列表，支持关键词搜索（用户名/显示名）。
- 默认展示最近有生成记录的用户，按最后生成时间倒序。
- 点击用户加载其会话。

### 6.3 第二层：会话与批次

- 中间展示该用户的会话列表。
- 展开会话显示其生成批次：
  - 批次类型：示例 / 全套。
  - 状态、商品名称、图片构成、张数、创建时间。
- 默认展开最近一个会话。

### 6.4 第三层：批次与单图

- 右侧展示选中批次的图片网格。
- 每张图显示缩略图、序号、状态角标。
- 点击图片打开单图详情抽屉。

### 6.5 筛选

| 筛选项 | 作用 |
| --- | --- |
| 用户 | 限定用户 |
| 商品名称 | 模糊匹配批次快照中的商品名称 |
| 图片角色（图片网格） | 主图 / 详情图 |
| 批次类型 | `sample` / `full` |
| 批次状态 | queued / running / sample_ready / confirmed / completed / partially_failed / failed / cancelled |
| 图片状态 | pending / generating / success / failed / superseded |
| 时间范围 | 按批次创建时间 |

- 筛选条件可组合。
- 查询结果为空时展示「没有符合条件的记录」。

### 6.6 分页

- 用户列表、会话列表、批次列表、图片网格分别分页。
- 默认每页 20 条/张。

## 8. 数据导出（仅超管）

### 8.1 入口

- 生图记录页右上角「导出数据」。
- 用户管理页右上角「导出数据」。
- 仅超管可见；管理员看不到按钮，直接调用接口返回 403。

### 8.2 导出范围

| 选项 | 说明 |
| --- | --- |
| 全部用户 | 导出全部业务数据 |
| 指定用户 | 选择一个或多个用户 |
| 时间范围 | 按批次创建时间过滤，可选 |

- 可选「包含操作日志」复选框，默认不勾选。

### 8.3 导出内容

ZIP 结构：

```
export_{yyyyMMddHHmmss}.zip
├── users.csv
├── sessions.csv
├── batches.csv
├── images.csv
├── audit_logs.csv          （勾选时）
├── manifest.json
└── images/
    └── {username}/
        └── {session_id}/
            └── {batch_id}/
                └── {index}_{image_id}.png
```

### 8.4 CSV 字段

| 文件 | 主要字段 |
| --- | --- |
| `users.csv` | 用户 ID、用户名、显示名、角色、状态、创建时间、最后登录 |
| `sessions.csv` | 会话 ID、用户 ID、标题、状态、需求摘要、创建时间 |
| `batches.csv` | 批次 ID、用户 ID、会话 ID、批次类型、商品名称、风格、尺寸、图片构成、状态、张数、创建时间 |
| `images.csv` | 图片 ID、批次 ID、序号、图片角色、状态、模型、耗时、Token、提示词、文件路径、是否历史可见、创建时间 |
| `audit_logs.csv` | 时间、操作人、动作、对象、结果、IP、详情摘要 |

- CSV 使用 UTF-8 带 BOM，便于 Excel 打开。
- 敏感字段不导出：密码哈希、API Key、JWT。

### 8.5 导出流程

1. 超管选择范围，点击「开始导出」。
2. 后端创建异步导出任务，返回 `job_id`。
3. 前端轮询任务状态：排队 / 执行中 / 完成 / 失败。
4. 完成后提供下载按钮，链接有效期 24 小时。
5. 导出文件存放于 MinIO `exports/` 前缀。
6. 任务状态存于 Redis，TTL 24 小时；过期后文件与状态一起清理。
7. 写入操作日志：导出开始、导出完成/失败。

### 8.6 限制

- 同一超管同时只允许 1 个导出任务。
- 导出数据量大时提示「导出任务已创建，完成后可在通知中下载」。
- 不提供直连数据库或 SQL 查询。
- 导出失败时展示原因，可重试。

## 9. 权限与数据边界

| 功能 | 管理员 | 超管 |
| --- | --- | --- |
| 概览 | ✓ | ✓ |
| Token 统计 | ✓ | ✓ |
| 生图记录查看 | ✓ | ✓ |
| 单图下载 | ✓ | ✓ |
| 数据导出 | ✗ | ✓ |
| 查看超管账号内容 | ✗ | ✓ |

- 管理员不能查看超管账号的会话与生图记录；列表与接口均需过滤。
- 所有查询按权限过滤，越权返回 403。
- 不提供删除生图记录与图片的入口。
- 导出不包含密码、API Key、JWT 等敏感信息。

## 11. 验收标准

1. 概览四张卡片的统计口径正确，数字与数据库一致。
2. 今日生成数、累计图片数只统计 `final` + `success` 的图片。
3. Token 统计支持时间、用户、Agent、模型筛选，汇总与明细一致。
4. 生图记录支持用户 → 会话 → 批次 → 单图钻取。
5. 批次筛选支持商品名称、批次类型、状态、时间；图片网格支持按图片角色筛选。
6. 单图详情展示提示词、模型、耗时、Token、状态、快照参数与图片。
7. 归档图片可查看元数据，大图/下载从归档读取并有 loading 提示。
8. 管理员看不到超管账号的内容。
9. 数据导出仅超管可用；管理员调用接口返回 403。
10. 导出 ZIP 包含 users/sessions/batches/images CSV 与图片目录，CSV 为 UTF-8 BOM。
11. 导出不含密码、API Key、JWT。
12. 导出任务异步执行，完成后 24 小时内可下载，过期清理。
13. 导出开始、完成、失败均写入操作日志。
14. 后台不提供删除生图记录、图片或直连数据库的入口。
