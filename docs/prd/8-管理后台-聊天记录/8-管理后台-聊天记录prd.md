## 1. 文档目的与范围

### 1.1 目的

定义管理后台的「内容追溯 → 聊天记录」与「Agent 配置」：管理员能查看用户与 Agent 的完整对话、每个 Agent 的中间调用与 Token；超管能配置豆包模型参数；管理员与超管能维护 8 个 Agent 的系统提示词。

### 1.2 本期范围

- 聊天记录列表、筛选、分页。
- 会话详情：消息流、Agent 标签、Token、关联生成批次。
- 展开查看每个 Agent 的调用明细。
- 消息关键词搜索（只读，不导出）。
- 模型配置（仅超管）。
- 系统提示词管理与版本历史（管理员、超管）。
- 相关权限与审计。

### 1.3 不做

- 管理员替用户发消息或继续对话。
- 聊天记录导出。
- 修改或删除聊天消息。
- 模型配置连通性测试按钮。
- 提示词 A/B 测试、效果对比。
- 新建 Agent 或删除 Agent。

## 3. 聊天记录列表

### 3.1 列表字段

| 字段 | 说明 |
| --- | --- |
| 用户 | 用户名 + 显示名 |
| 会话标题 | 会话名称；已隐藏会话带「已隐藏」标签 |
| 消息数 | 用户 + Agent + 系统消息总数 |
| 最后消息时间 | 本地时区 |
| 累计 Token | 该会话所有 Agent 调用的输入 + 输出 |
| 关联批次 | 该会话的生成批次数 |
| 状态 | 活跃 / 已隐藏 |

### 3.2 筛选

| 筛选项 | 说明 |
| --- | --- |
| 用户关键词 | 匹配用户名或显示名 |
| 会话标题关键词 | 模糊匹配 |
| 时间范围 | 按最后消息时间 |
| 状态 | 活跃 / 已隐藏 / 全部 |

- 默认按最后消息时间倒序。
- 分页每页 20 条，可切换 20/50/100。
- 管理员不能看到超管账号的会话；超管可看全部。

### 3.3 操作

- 点击行进入会话详情。
- 不提供删除、导出、编辑。
- 不提供「以该用户身份继续对话」。

## 4. 会话详情

### 4.1 布局

```
┌──────────────────────────────────────────────────────────────┐
│ 返回列表   会话：秋季通勤衬衫   用户：张三   状态：活跃       │
│ 消息数 18   累计 Token 12,340   关联批次 2                    │
├──────────────────────────────────────────────────────────────┤
│ [用户] 帮我做一套图，风格简洁一点                              │
│ [规划 Agent] 好的，我先确认几个信息…                          │
│   └ 展开 Agent 调用明细 ▾                                     │
│ [商品理解 Agent] 已识别为服饰类目…                            │
│   └ 展开 Agent 调用明细 ▾                                     │
│ [系统] 示例图已生成                                           │
│ [用户] 背景再亮一点                                          │
│ ...                                                          │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 消息展示

- 按时间正序排列。
- 用户消息右侧、Agent 消息左侧、系统消息居中。
- Agent 消息显示 Agent 名称标签（规划 Agent、商品理解 Agent 等）。
- 每条消息显示时间、Token（Agent 消息）。
- 消息内容支持 Markdown 基础渲染，禁止原始 HTML。
- 关联生成批次的消息，显示「查看批次」按钮，跳转生图详情。
- 消息默认加载最新一页，向上滚动自动加载更早消息（滚动加载，不采用分页器）。

### 4.3 顶部摘要

| 信息 | 说明 |
| --- | --- |
| 会话标题 | 可查看，不可修改 |
| 用户 | 用户名 + 显示名，可跳转用户详情 |
| 状态 | 活跃 / 已隐藏 |
| 消息数 | 总消息数 |
| 累计 Token | 输入 + 输出 |
| 关联批次 | 批次数量，可跳转生图记录 |

### 4.4 只读

- 后台不能发送消息、编辑消息、删除消息。
- 不能恢复已隐藏会话（恢复由用户侧决定，本期不提供）。
- 不能查看用户密码等敏感信息。

## 5. Agent 调用明细

### 5.1 展开方式

- Agent 消息下方提供「展开 Agent 调用明细」。
- 一次回复可能包含多个 Agent 调用，按顺序展示。

### 5.2 明细字段

| 字段 | 说明 |
| --- | --- |
| Agent | 名称 + `agent_code` |
| 状态 | success / failed / skipped |
| 开始时间 | 本地时区 |
| 耗时 | 毫秒 |
| 输入 Token | 数值 |
| 输出 Token | 数值 |
| 输入摘要 | 最多 2000 字符；超长截断 |
| 输出摘要 | 最多 2000 字符；超长截断 |
| 错误信息 | 失败原因 |
| 模型 | 使用的模型名 |

### 5.3 权限

- 管理员：查看输入/输出摘要。
- 超管：可切换「查看完整输入/输出」（仅展示已存储内容，不重新调用模型）。
- 系统提示词内容不在明细中直接展示；如需查看，跳转「Agent 配置 → 系统提示词」。

### 5.4 不展示

- 不展示模型原始请求体中的 API Key。
- 不展示内部思维链。
- 不展示用户上传图的二进制内容；如需查看，跳转批次详情。

## 6. 消息搜索

### 6.1 搜索入口

- 聊天记录列表顶部搜索框。
- 输入关键词后，搜索消息内容。

### 6.2 搜索规则

- 大小写不敏感的子串匹配。
- 仅搜索当前管理员可见范围内的消息。
- 结果按消息时间倒序，每页 20 条。
- 每条结果显示：用户、会话标题、消息角色、消息摘要（关键词高亮）、时间。
- 点击结果进入会话详情并定位到该消息。

### 6.3 限制

- 不提供正则、布尔组合、字段限定。
- 不提供导出。
- 不做全文索引优化；数据量大时使用 PostgreSQL `ILIKE` + 索引，必要时后续升级为全文检索。

## 7. 模型配置（仅超管）

### 7.1 页面字段

| 字段 | 类型 | 规则 | 默认 |
| --- | --- | --- | --- |
| 服务商 | 只读 | 豆包（火山方舟） | 豆包 |
| Base URL | 输入框 | 合法的 http/https 地址 | 火山方舟默认地址 |
| API Key | 密码框 | 保存后加密；展示脱敏 | 空 |
| 文本模型 | 输入框 | 模型名，非空 | 待接入时确认 |
| 图像模型 | 输入框 | 模型名，非空 | 待接入时确认 |
| 视觉模型 | 输入框 | 模型名，可为空；为空时质量审核跳过并标记「未校验」 | 空 |
| 温度 | 数字 | 0~2，步长 0.1 | 0.7 |
| 超时秒数 | 数字 | 30~300 | 120 |
| 并发数 | 数字 | 1~16 | 4 |
| 重试次数 | 数字 | 0~3 | 1 |
| 上下文 Token 上限 | 数字 | 1024~128000 | 待接入时确认 |

> 重试次数为 **HTTP 瞬态重试**（连接失败/429/5xx 立即重试）；业务层重试为 4 号文档定义的 10 次指数退避，两层叠加。
> 并发数为**豆包侧并发上限**（信号量限制同时调用豆包的请求数）；11 号文档的 `WORKER_CONCURRENCY` 为 worker 进程/协程数，两者分层，不互相替代。

### 7.2 API Key 处理

- 保存时使用对称加密（如 AES-GCM）后写入数据库；加密密钥来自环境变量。
- 页面只展示脱敏值，如 `sk-****abcd`。
- 修改时需重新输入完整 Key；不提供「查看明文」。
- 日志与审计中不得记录完整 Key。
- 未配置 Key 时，生成与聊天接口返回「模型未配置」错误。

### 7.3 保存与生效

1. 超管修改字段，点击保存。
2. 后端校验数值范围、URL 格式；文本模型与图像模型名非空，视觉模型可为空。
3. 保存写入 `model_configs`，刷新后端配置缓存。
4. 新配置对**下一次调用**生效；进行中的任务使用旧配置。
5. 写入操作日志：记录变更字段，不记录 Key 明文。
6. 不做连通性测试；保存成功不代表 Key 可用。

### 7.4 权限

- 仅超管可见「Agent 配置 → 模型配置」。
- 管理员访问接口返回 403。
- 模型配置变更不影响历史 `agent_runs` 中记录的模型名。

## 8. 系统提示词管理

### 8.1 页面结构

| 区域 | 内容 |
| --- | --- |
| 左侧 | 8 个 Agent 列表，显示当前版本、更新时间 |
| 右侧 | 当前提示词内容、版本历史、保存按钮 |

### 8.2 Agent 列表

| Agent | `agent_code` |
| --- | --- |
| 规划 Agent | `planner` |
| 商品理解 Agent | `product_understanding` |
| 文案 Agent | `copywriter` |
| 提示词 Agent | `prompt_builder` |
| 生图执行 Agent | `image_generator` |
| 质量审核 Agent | `quality_reviewer` |
| 修复 Agent | `repairer` |
| 平台规范 Agent | `platform_rule` |

> `platform_rule` Agent 的系统提示词同时承载平台规范规则（尺寸、违禁词、类目），由管理员/超管维护，随提示词版本保存与回滚。

### 8.3 编辑规则

- 文本框编辑当前提示词，最大 20000 字符。
- 保存时创建新版本，并把新版本设为启用。
- 旧版本保留在版本历史中，可查看、可回滚。
- 回滚会基于旧版本内容创建一个新版本，不直接删除新版本。
- 保存前校验非空；按 §8.5 维护每个 Agent 的「建议变量」清单，保存时未引用建议变量给出警告但允许保存；引用未知变量原样保留并在保存时提示。
- 变更对下一次调用生效，进行中的任务使用旧提示词。
- 写入操作日志：记录 Agent、版本号、修改人。

### 8.4 版本历史

| 字段 | 说明 |
| --- | --- |
| 版本号 | 递增整数 |
| 内容 | 可查看全文 |
| 修改人 | 用户名 |
| 修改时间 | 本地时区 |
| 状态 | 当前启用 / 历史 |

- 支持查看历史版本全文。
- 支持回滚。
- 不提供版本对比（diff）。

### 8.5 可用变量

提示词中可使用以下占位变量，由后端在调用前替换：

| 变量 | 说明 | 适用 Agent |
| --- | --- | --- |
| `{{product_name}}` | 商品名称 | 规划、商品理解、文案、提示词 |
| `{{params}}` | 参数快照 JSON | 规划、商品理解、文案、提示词 |
| `{{requirement_summary}}` | 需求摘要 JSON | 规划、商品理解、文案、提示词 |
| `{{chat_summary}}` | 最近 10 轮聊天摘要 | 规划、商品理解、文案 |
| `{{product_profile}}` | 商品画像 JSON | 文案、提示词、审核、修复 |
| `{{plan}}` | 任务计划 JSON | 文案、提示词 |
| `{{copy_blocks}}` | 文案块 JSON | 提示词、平台规范 |
| `{{review_issues}}` | 审核问题 JSON | 修复 |
| `{{platform_rules}}` | 平台规范内容，取自 `platform_rule` 系统提示词 | 文案、平台规范 |

- 变量名区分大小写。
- 未知变量原样保留，并在保存时提示。
- 生图执行 Agent 的提示词主要用于系统级约束，其具体画面描述来自提示词 Agent。

### 8.6 权限

| 操作 | 管理员 | 超管 |
| --- | --- | --- |
| 查看提示词与版本 | ✓ | ✓ |
| 编辑、保存新版本 | ✓ | ✓ |
| 回滚 | ✓ | ✓ |
| 查看其他超管内容 | ✗ | ✓ |

- 管理员可编辑全部 8 个 Agent 的提示词。
- 提示词变更写入操作日志。

## 9. 权限与数据边界

| 功能 | 管理员 | 超管 |
| --- | --- | --- |
| 聊天记录列表与详情 | ✓（不含超管账号） | ✓ |
| Agent 调用明细摘要 | ✓ | ✓ |
| Agent 调用完整内容 | ✗ | ✓ |
| 消息搜索 | ✓（可见范围） | ✓ |
| 模型配置 | ✗ | ✓ |
| 系统提示词查看/编辑 | ✓ | ✓ |
| 聊天记录导出 | ✗ | ✗ |

- 聊天记录只读，任何角色都不能修改或删除。
- 管理员不能查看超管账号的会话与消息；接口层过滤。
- 提示词与模型配置变更写入操作日志，不记录敏感明文。
- 聊天记录随业务数据保留 5 年，之后转归档；归档期间仍可查询元数据与消息内容（消息在数据库中，不随图片归档）。

## 11. 验收标准

1. 聊天记录列表支持用户、会话标题、时间、状态筛选与分页。
2. 管理员看不到超管账号的会话；超管可看全部。
3. 会话详情按时间正序展示用户、Agent、系统消息，Agent 消息带名称标签。
4. 每条 Agent 消息可展开查看对应 `agent_runs` 的 Agent、状态、耗时、Token、输入/输出摘要。
5. 超管可查看完整输入/输出；管理员只能看摘要。
6. 消息搜索大小写不敏感，结果高亮关键词，可定位到会话中的消息。
7. 聊天记录不提供导出、编辑、删除入口。
8. 模型配置仅超管可见，API Key 加密存储、页面脱敏、不可回显。
9. 模型配置保存后对下一次调用生效，进行中任务使用旧配置。
10. 模型配置变更写入操作日志，不记录 Key 明文。
11. 系统提示词按 8 个 Agent 管理，可编辑、保存新版本、查看历史、回滚。
12. 提示词变更对下一次调用生效，版本历史完整。
13. 管理员与超管均可编辑提示词，变更写入操作日志。
14. 提示词支持约定变量替换，未知变量保存时提示。
