# 01: 8 号后台骨架、种子夹具与聊天记录列表

**What to build:** 管理员或超管登录后，管理后台出现「内容追溯 → 聊天记录」「Agent 配置 → 模型配置」「Agent 配置 → 系统提示词」三个入口；进入聊天记录页能看到分页的会话列表，按用户、会话标题、最后消息时间、状态筛选；管理员看不到超管账号的会话，超管可看全部；普通用户访问管理端页面跳 `/403`、接口返回 403。演示数据由幂等种子夹具提供，demo 可独立重复演示。

**Blocked by:** 1 号 demo 的 01~03（工程骨架、登录闭环、登录态与路由守卫）+ 6 号 demo 的 01（管理后台骨架、权限中间件、23 个权限点种子）

**Status:** ready-for-agent

- [ ] 管理后台新增「内容追溯 → 聊天记录」菜单与路由，`admin.content.view` 可见；新增「Agent 配置」菜单组，下含「模型配置」（仅 `admin.model.view`）与「系统提示词」（`admin.prompts.view`）；无权限时菜单不显示，直接访问跳 `/403`。
- [ ] 新增 4 张内容表的最小建表脚本（`creative_sessions`、`chat_messages`、`agent_runs`、`generation_batches`），字段与 10 号 §4.6~§4.9 一致；使用 `CREATE TABLE IF NOT EXISTS`，已存在则跳过，不修改 2/3/4 号 demo 已建表结构。
- [ ] 幂等种子写入 `demo_user` 的 3 个会话（1 个 `hidden`、2 个 `active`）与 `demo_super` 的 1 个会话，以及对应消息、Agent 调用、生成批次；重复执行不覆盖已有数据，以 `(user_id, title)` 识别。
- [ ] 种子包含 `success` / `failed` / `skipped` 三种 Agent 调用状态；至少 1 条 Agent 调用通过 `batch_id` 关联生成批次；至少 1 条消息含「衬衫」、1 条含 `T-shirt`、1 条超管会话消息含「超管」。
- [ ] 会话列表返回用户（用户名 + 显示名）、会话标题、消息数（用户 + Agent + 系统消息总数）、最后消息时间、累计 Token（该会话全部 `agent_runs` 输入 + 输出）、关联批次数、状态（`active` / `hidden`）。
- [ ] 支持 `user_keyword`（用户名或显示名模糊）、`title_keyword`（会话标题模糊）、`last_message_from` / `last_message_to`（按最后消息时间的本地日期范围）、`status`（`active` / `hidden` / `all`，默认 `all`）、`page`、`page_size`（20/50/100，默认 20）。
- [ ] 默认按最后消息时间倒序、ID 倒序；筛选条件变化后前端回到第 1 页；最后消息时间为空时按创建时间参与排序。
- [ ] 管理员可见范围内排除拥有 `super_admin` 角色的账号的会话；超管可见全部；过滤在接口层完成，不能只靠前端隐藏。
- [ ] 列表展示「已隐藏」标签；空结果显示「暂无聊天记录」；加载失败显示「加载失败，点击重试」。
- [ ] 列表不提供删除、导出、编辑、恢复会话、以用户身份继续对话的入口。
- [ ] 普通用户访问列表接口返回 403 `20005`；未登录返回 401。
- [ ] 接口与页面各有可执行的冒烟测试，关键步骤输出中文日志。
