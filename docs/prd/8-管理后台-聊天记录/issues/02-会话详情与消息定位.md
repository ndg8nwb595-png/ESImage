# 02: 会话详情、消息流与消息定位

**What to build:** 管理员从列表进入某个会话，看到顶部摘要与按时间正序的消息流：用户消息在右、Agent 消息在左并带 Agent 名称标签、系统消息居中；Agent 消息显示 Token，关联批次的消息显示「查看批次」入口。默认加载最新一页，向上滚动自动加载更早消息；从搜索结果进入时通过锚点消息定位到上下文。整个页面只读，不能发送、编辑、删除或恢复会话。

**Blocked by:** 01（8 号后台骨架、种子夹具与聊天记录列表）

**Status:** ready-for-agent

- [ ] 会话详情接口返回顶部摘要：会话标题（只读）、用户（用户名 + 显示名，可跳转用户详情）、状态、消息总数、累计 Token、关联批次数、最后消息时间、创建时间。
- [ ] 消息按时间正序返回；每条包含角色（`user` / `assistant` / `system`）、`agent_code`、Agent 中文名、正文、内容类型、消息 Token、消息状态、创建时间。
- [ ] Agent 消息返回其全部 `agent_runs` 摘要（ID、Agent、状态、耗时、输入/输出 Token、模型），供前端展开；系统消息与用户消息的 `agent_runs` 为空。
- [ ] 关联批次通过 `agent_runs.message_id → batch_id` 推导；消息返回关联批次的 ID、类型、状态、商品名称、创建时间；无关联时返回空数组。
- [ ] 默认返回最新 `limit` 条消息（默认 20、最大 50）；支持 `before_id` 加载更早消息，返回 `has_older` / `has_newer`；向上滚动到顶后显示「没有更早的消息」。
- [ ] 支持 `around_id` 定位：返回锚点前后窗口，总数不超过 `limit`；响应带 `anchor_message_id`；`before_id` 与 `around_id` 同时出现时返回 400 `10001`。
- [ ] 消息流不使用分页器；滚动加载不重复、不跳过消息。
- [ ] Agent 消息支持基础 Markdown 渲染（加粗、斜体、列表、换行、行内代码），禁止原始 HTML；用户消息保留换行、不解析 Markdown。
- [ ] 「查看批次」打开只读批次摘要抽屉（批次 ID、类型、状态、商品名称、创建时间）；完整生图详情页显示「7 号 PRD 实现后开放」。
- [ ] 管理员可打开非超管账号的会话（含 `hidden`）；打开超管账号的会话返回 403 `20005`；不存在的会话返回 404 `30013`。
- [ ] 页面不提供发送消息、编辑消息、删除消息、恢复会话、导出入口；不展示密码等敏感信息。
- [ ] 接口与页面各有可执行的冒烟测试，关键步骤输出中文日志。
