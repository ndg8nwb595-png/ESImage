# 03: Agent 调用明细

**What to build:** 管理员在会话详情中展开某条 Agent 消息，看到一个或多个按顺序排列的 Agent 调用；点开某条调用能看到 Agent 名称与 `agent_code`、状态、开始时间、耗时、输入/输出 Token、输入摘要、输出摘要、错误信息与模型。管理员只能看摘要；超管可切换查看已存储的完整输入/输出，不会重新调用模型，也不会看到 API Key 明文、思维链或图片二进制。

**Blocked by:** 02（会话详情、消息流与消息定位）

**Status:** ready-for-agent

- [ ] Agent 调用明细接口返回：Agent 名称 + `agent_code`、状态（`success` / `failed` / `skipped`）、开始时间、耗时毫秒、输入 Token、输出 Token、输入摘要、输出摘要、错误信息、模型名、关联的会话/消息/批次/图片 ID。
- [ ] 开始时间取 `agent_runs.created_at`；耗时取 `latency_ms`；Token 取 `prompt_tokens` / `completion_tokens`。
- [ ] 默认只返回输入/输出摘要；摘要按存储内容原样返回，不在后台二次截断或改写。
- [ ] 超管传 `full=true` 时返回已存储的完整输入/输出；`full=false` 或未传时完整字段为 `null`；响应带 `full_available` 标识当前角色是否可看完整内容。
- [ ] 管理员传 `full=true` 返回 403 `20005`；管理员正常请求只得到摘要。
- [ ] 不存在的调用返回 404 `30020`；管理员访问超管会话下的调用返回 403 `20005`。
- [ ] 响应不包含 API Key、密码、JWT、内部思维链、用户上传图二进制；完整内容为存储前已脱敏的文本。
- [ ] 会话详情中的 Agent 消息能展开多条调用，按调用顺序展示；失败调用显示错误信息，跳过调用显示「已跳过」。
- [ ] 页面不提供重新调用模型、编辑输入/输出、删除调用记录的入口。
- [ ] 接口与页面各有可执行的冒烟测试，关键步骤输出中文日志。
