# 05: 模型配置读取与保存

**What to build:** 超管进入「Agent 配置 → 模型配置」，看到豆包服务商、Base URL、脱敏 API Key、文本/图像/视觉模型、温度、超时、并发、重试、上下文 Token 上限；修改并保存后配置写入数据库，下一次调用使用新配置。API Key 加密存储、页面只显示脱敏值、不可回显、日志与审计不记录明文；管理员看不到菜单，直接访问接口返回 403。不提供连通性测试。

**Blocked by:** 01（8 号后台骨架、种子夹具与聊天记录列表）

**Status:** ready-for-agent

- [ ] 「Agent 配置 → 模型配置」仅 `admin.model.view` 可见；管理员与普通用户不显示菜单，直接访问页面跳 `/403`、接口返回 403 `20005`。
- [ ] 读取接口返回服务商（固定豆包/火山方舟）、Base URL、脱敏 API Key、`api_key_configured`、文本模型、图像模型、视觉模型、温度、超时秒数、并发数、重试次数、上下文 Token 上限、最后修改人与时间。
- [ ] API Key 为空时不返回值，`api_key_configured=false`；已配置时只返回形如 `sk-****abcd` 的脱敏值，任何接口都不返回明文。
- [ ] 保存接口校验：Base URL 为合法 `http/https` 地址；文本模型、图像模型非空；视觉模型可为空；温度 0~2 且步长 0.1；超时 30~300；并发 1~16；重试 0~3；上下文上限 1024~128000 或为空；服务商只读，传入其他值返回 400。
- [ ] 参数错误返回 `10001` / `10002` / `10003` / `10004`；校验失败不写库。
- [ ] `api_key` 省略、`null` 或空字符串表示不修改；非空则用 AES-256-GCM 加密后覆盖；加密密钥来自环境变量 `MODEL_CONFIG_ENCRYPTION_KEY`，缺失或格式错误时应用启动失败并给出明确提示。
- [ ] 保存写入单条启用配置（`is_active=true`），刷新后端配置读取；本 demo 每次读取直查数据库，不接缓存；进行中的任务使用旧配置的语义由后续调用方保证。
- [ ] 保存写操作日志 `model_config.update`，记录变更字段名与是否修改 Key，不记录 Key 明文、密文或可逆信息。
- [ ] 页面提供保存按钮与校验提示；不提供「查看明文」、连通性测试、Key 清除、Key 轮换入口；保存成功不代表 Key 可用。
- [ ] 接口与页面各有可执行的冒烟测试，关键步骤输出中文日志。
