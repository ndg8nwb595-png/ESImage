# 06: 系统提示词管理与版本

**What to build:** 管理员或超管进入「Agent 配置 → 系统提示词」，左侧看到 8 个 Agent 与当前版本、更新时间；右侧查看当前提示词、版本历史并编辑保存。保存生成新版本并立即设为当前；回滚基于旧版本内容再生成一个新版本，不删除已有版本。保存时对建议变量缺失与未知变量给出警告但允许保存；所有变更写操作日志。

**Blocked by:** 01（8 号后台骨架、种子夹具与聊天记录列表）

**Status:** ready-for-agent

- [ ] 「Agent 配置 → 系统提示词」对 `admin.prompts.view` 可见；管理员与超管均可查看、编辑、保存、回滚；普通用户访问接口返回 403 `20005`。
- [ ] 种子幂等写入 8 个 Agent（`planner`、`product_understanding`、`copywriter`、`prompt_builder`、`image_generator`、`quality_reviewer`、`repairer`、`platform_rule`）的提示词与版本 1；已存在则跳过，不覆盖已修改内容。
- [ ] 列表返回 8 个 Agent 的名称、`agent_code`、当前版本号、更新时间、修改人、内容预览；按固定 Agent 顺序展示，不分页。
- [ ] 详情返回当前提示词全文、当前版本、修改人与时间、建议变量清单、正文中实际引用的变量、全部版本历史（版本号、全文、修改人、时间、是否当前）。
- [ ] 保存接口接收提示词全文；去除首尾空格后为空返回 400 `10002`，超过 20000 字符返回 400 `10004`；保存成功生成新版本号（当前版本 + 1），写入版本历史并设为当前。
- [ ] 变量识别区分大小写；未知变量原样保留并返回 `unknown_variables` 警告；建议变量未引用返回 `missing_suggested_variables` 警告；有警告仍保存成功。
- [ ] 回滚接口接收目标版本号；版本不存在返回 404 `30022`；回滚复制目标版本内容生成新版本（当前版本 + 1），不删除或改写任何历史版本。
- [ ] Agent 不存在返回 404 `30021`；列表/详情/保存/回滚均使用当前数据库内容，不重新调用模型。
- [ ] 保存写操作日志 `prompt.update`（Agent、版本号、修改人、变量警告）；回滚写 `prompt.rollback`（Agent、源版本、新版本、修改人）；不记录敏感明文。
- [ ] 页面不提供 diff、A/B 测试、效果对比、新建 Agent、删除 Agent、删除版本入口；提示词内容不嵌入 Agent 调用明细。
- [ ] 接口与页面各有可执行的冒烟测试，关键步骤输出中文日志。
