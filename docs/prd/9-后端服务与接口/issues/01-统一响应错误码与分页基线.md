# 01: 统一响应、错误码、参数校验与分页基线

**What to build:** 所有联调方（前端、`curl`、契约回归套件）看到一致的响应形状：成功与失败都返回 `{ code, message, data }`，HTTP 状态与业务码成对出现；缺少必填参数、格式错误、超出范围分别得到 `10002` / `10003` / `10004`；分页接口统一返回 `{ items, total, page, page_size }`，页码越界与页大小超限的行为一致。用 `POST /auth/login`、`GET /auth/me`、`GET /sessions/{id}/messages` 这三个既有接口验证，不新增业务接口。

**Blocked by:** 1 号 demo 的 01~03（工程骨架、登录闭环、登录态与路由守卫）

**Status:** ready-for-agent

- [ ] 除文件流、ZIP 流与 SSE 外，所有接口成功时返回 `code=0`、`message="ok"`、`data` 为对象/数组；失败时 `code` 为非 0 业务码，`data` 为 `null` 或补充信息，字段不省略。
- [ ] HTTP 状态与业务码成对：参数问题 400 + `1xxx`；未登录/过期 401 + `2xxx`；无权限/账号不可用 403 + `2xxx`；不存在 404 + `3xxx`；状态冲突 409 + `3xxx`；系统异常 500 + `5xxx`。不出现「HTTP 200 + 业务错误码」。
- [ ] 缺少必填参数返回 400 `10002`，`message` 指明字段名；字段类型/日期/UUID/枚举格式错误返回 400 `10003`；长度、数值、分页大小越界返回 400 `10004`；其余参数问题返回 400 `10001`。
- [ ] 未捕获异常返回 500 `50001`，数据库异常 `50002`，存储异常 `50003`；响应体不包含堆栈、SQL、内部路径或上游模型原始错误。
- [ ] 字段统一 `snake_case`；空值为 `null` 且不省略键；布尔值为 `true` / `false`；时间为 ISO 8601 带时区；ID 为整数。
- [ ] 分页请求 `page` 默认 1、`page_size` 默认 20、最大 100；`page<1` 返回 400 `10001`，`page_size` 不在 1~100 返回 400 `10004`，非整数返回 400 `10003`。
- [ ] 分页响应固定为 `data.items` / `data.total` / `data.page` / `data.page_size`；无数据时 `items=[]`；页码超过总页数时返回 200、`items=[]`、`total` 为真实总数。
- [ ] 分页排序包含唯一键兜底（如 `created_at DESC, id DESC`），连续翻页不重复、不遗漏；过滤在数据库层完成，不返回已删除、已隐藏或他人的数据。
- [ ] `POST /auth/login` 密码错误返回 HTTP 401 `20001`；缺少用户名或密码返回 400 `10002`；成功返回统一结构且 `data` 含 `token`、`expires_at`、`user`。
- [ ] `GET /sessions/{id}/messages` 返回统一分页结构；页码与页大小行为符合上述约定。
- [ ] 契约回归套件覆盖上述用例，每个用例输出中文日志：请求、预期状态、预期业务码、实际状态、实际业务码、结论。
- [ ] 不新增业务接口，不改变 1~6 号 demo 已定义的业务字段与业务语义。
