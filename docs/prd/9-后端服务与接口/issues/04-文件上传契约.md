# 04: 文件上传契约

**What to build:** 用户通过 `POST /uploads` 上传商品图时，服务端按统一契约校验字段、格式、大小、可解码性与数量：只接受 JPG/PNG/WEBP、单张 ≤10MB、能完整解码；未绑定会话的有效上传图最多 5 张。合法上传返回 `upload_id`、`file_url`、`thumbnail_url`、`width`、`height`、`size_bytes`；非法文件统一返回 400 `30006`，提示可直接展示。上传图只能被本人读取与软删除，原件经鉴权流式返回，缩略图保留预签名 URL 的有效期与权限语义。

**Blocked by:** 03（权限点校验与越权语义）；2 号 demo 03（上传接口与存储适配层）

**Status:** ready-for-agent

- [ ] `POST /uploads` 使用 `multipart/form-data`，字段名固定为 `file`；缺少 `file` 返回 400 `10002`。
- [ ] 扩展名只接受 `.jpg` / `.jpeg` / `.png` / `.webp`；MIME 只接受 `image/jpeg` / `image/png` / `image/webp`；文件头必须与声明格式一致，不能只信扩展名与 MIME。
- [ ] 单张大小 ≤10MB；超过返回 400 `30006`，`message` 为「单张图片不能超过 10MB」。
- [ ] 图片必须能被完整解码且宽高 > 0；损坏或截断返回 400 `30006`，`message` 为「图片文件损坏，请重新上传」。
- [ ] 当前用户「`session_id IS NULL` 且 `status=active`」的上传总数最多 5 张；第 6 张返回 400 `30006`，`message` 为「最多上传 5 张商品图」；绑定会话后释放名额。
- [ ] 合法上传返回 `upload_id`、`file_url`、`thumbnail_url`、`width`、`height`、`size_bytes`；URL 为相对路径，不包含 token、签名或存储桶密钥。
- [ ] `GET /uploads/{upload_id}` 返回同一组元数据；`DELETE /uploads/{upload_id}` 为软删除，删除后不再出现在会话与名额统计中。
- [ ] 读取或删除他人上传图、已删除上传图、已绑定其他会话的上传图 → 404 `30014`；缺少 `user.generate` 权限码 → 403 `20005`；不泄露存在性。
- [ ] 原件通过带鉴权的 `/content` 流式读取；缩略图通过 `/thumbnail` 读取或使用预签名 URL；预签名 URL 签发前校验权限、有效期 ≤5 分钟，失效后不返回文件。
- [ ] 最小 demo 沿用 2 号 demo 的本地存储适配层与带鉴权缩略图读取；不接 MinIO；预签名用本地 HMAC 适配器模拟，保留有效期与权限校验语义。
- [ ] 契约回归套件覆盖「合法 JPG/PNG/WEBP、GIF、超 10MB、损坏图、第 6 张、他人上传图、删除后读取」八类场景，每个用例输出中文日志。
- [ ] 不新增上传业务接口，不改变 2 号 demo 已定义的响应字段与存储路径契约。
