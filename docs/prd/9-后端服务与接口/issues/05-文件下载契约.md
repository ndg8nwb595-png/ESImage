# 05: 文件下载契约

**What to build:** 用户从结果区或历史页下载单张正式图或整组 ZIP 时，后端先校验归属与权限，再以流式方式返回文件：单张返回 PNG，整组返回含图片与 `manifest.csv` 的 ZIP；`Content-Disposition` 使用 RFC 5987 编码，中文商品名称不乱码。图片不存在、不属于当前用户或归档不可用时返回 404 `30014`；示例图确认前、批次状态不允许整组下载时返回 409 `30005`。缩略图预签名 URL 保留「签发前校验权限、有效期 ≤5 分钟」的契约，原件不走预签名。

**Blocked by:** 03（权限点校验与越权语义）；5 号 demo 03~04（单张下载、整组 ZIP 与归档读取）

**Status:** ready-for-agent

- [ ] `GET /images/{image_id}/download` 返回 `Content-Type: image/png` 与文件流；`GET /batches/{batch_id}/download` 返回 ZIP 流，ZIP 内含按 `index` 升序的图片与根目录 `manifest.csv`。
- [ ] `Content-Disposition` 使用 `attachment; filename*=UTF-8''<percent-encoded>`；中文商品名称、主图/详情图标识、序号与时间戳均正确；不额外约定 ASCII 回退字段。
- [ ] 单张文件名规则为 `{商品名称}_{主图|详情图}_{序号}_{yyyyMMddHHmmss}.png`；ZIP 文件名为 `{商品名称}_全套_{yyyyMMddHHmmss}.zip`；时间戳取图片或批次的 `created_at`，按 Asia/Shanghai 计算。
- [ ] 文件流边读边写，不把整张图或整个 ZIP 一次性读入内存；ZIP 生成失败时不返回残缺压缩包，整个请求失败并记录服务端日志。
- [ ] 下载前校验当前用户对图片/批次的归属与权限码；越权返回 403 `20005` 或 404 `30014`，不泄露资源内容、名称与数量。
- [ ] 图片不存在、不属于当前用户、缩略图缺失 → 404 `30014`；归档对象不可用 → 404 `30014`，`message` 为「文件归档中，请稍后重试」。
- [ ] 示例图确认前下载 → 409 `30005`；批次状态不允许整组下载 → 409 `30005`；错误响应使用统一 JSON 结构。
- [ ] `archived_at IS NULL` 时读取热存储路径；`archived_at` 非空时读取 `archive/` 前缀；归档不可用不降级为热存储路径，避免读到错误文件。
- [ ] `GET /images/{image_id}/thumbnail` 与 `/content` 的权限、内容类型与错误码符合 2/5 号 demo 约定；缩略图预签名 URL 签发前校验权限、有效期 ≤5 分钟，过期或签名不匹配返回 403 `20005` 或 404 `30014`。
- [ ] 最小 demo 不接 MinIO；预签名用本地 HMAC 适配器模拟；不做 5 年归档任务，用文件缺失或归档路径缺失模拟 `30014` 降级。
- [ ] 契约回归套件覆盖「单张下载、整组 ZIP、中文文件名、无权限、他人图片、示例图、归档不可用、残缺 ZIP 不返回」八类场景，每个用例输出中文日志。
- [ ] 不新增下载业务接口，不改变 2/5 号 demo 已定义的文件名规则与 ZIP 结构。
